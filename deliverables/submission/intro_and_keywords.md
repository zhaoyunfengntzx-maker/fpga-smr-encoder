# 作品简介（提交系统可直接粘贴）

**作品名称：基于FPGA的细分编码器**

本作品面向伺服驱动、数控转台与机器人关节对高分辨、抗污染位置反馈的需求，设计了一款基于 SMR 磁阻传感器与 FPGA 的高精度细分磁编码器。系统以 XC7A35TFGG484-2 为唯一计算单元，在 50 MHz 单时钟域内完成双通道 12 bit、65 MSPS 同步采样，片内 ÷4 抽取与数字滤波，偏置/增益/正交相位/残余位移六参数闭式校正，17 级全流水 CORDIC 相位解算，II 型 PI 跟踪与增量展开，输出 16 位绝对角度（0.0055°/LSB）以及 ABZ、UVW+Z、1 GbE UDP、UART/SPI 多协议接口，并集成 1024×600 触摸屏诊断界面与上位机实时显示、在线调参。六参数校正由一阶/二阶矩阵一次解算，无需查找表与上位机迭代；正反向 UVW 采用对称宽基分支，消除 0/5 扇区回绕吞并；多圈计数以无符号差分零扩展累加，消除跨半量程符号扩展死锁；全链路 41.5 拍、约 830 ns 的确定性延迟，适合高刚性速度环。作品还提供信号质量评估、零位捕获、故障报警与寄存器级在线调试。基于 2048 周期/转磁环的 v74 生产位流（BUILD 0x0018）已在真实转台上完成闭环验证：719–731 rpm、Z 12.00 Hz、单圈 2048 个电周期无丢拍、UVW 六态均匀、60 s 连续上传 598,115 帧；资源 10,926 LUT（52.53%）、8,697 FF、32/50 BRAM、17 DSP，WNS +0.409 ns、0 失败端点（24,625 个），位流 1,512,664 B、SHA-256 E4634907…DA2680。作品以“建模—位精确仿真—构建签核—真机判据”的证据链交付，配套 54 个仿真台、263 件可追溯证据与一条命令签核，可直接用于伺服、机床、机器人关节等场景。

## 三个创新关键词（定稿）

1. **闭式自校准**——六参数一阶/二阶矩一次解算，椭圆→单位圆，无查找表、无上位机迭代。
2. **多协议同源**——ABZ / UVW+Z / SPI / 1 GbE UDP / UI 共用同一 32 位角度字，可观测、可审计。
3. **高精度细分**——SMR 磁阻 + 2048 周期/转磁环，单 FPGA 完成 16 位细分（0.0055°/LSB），真机 2048 个电周期无丢拍。
