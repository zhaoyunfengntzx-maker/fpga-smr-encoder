## 1. 功能需求

### F1 标准色轮流显示

* 8 色循环：**白 → 黑 → 红 → 绿 → 蓝 → 青 → 品红 → 黄**，整屏满幅
* 每色停留 **1.0 s**（常数可配）
* 屏上信息（不遮挡主色区，压在四角）：
  * 左上：色名 + 序号（`WHITE  1/8`）
  * 右上：RGB888 十六进制值（`FFFFFF`）
  * 右下：刷新/连续运行计数
* 用途：肉眼查坏点、色偏、背光均匀性、24 位数据线接反/错位
* 说明：**不做**灰阶与单通道 ramp（本轮需求未选）

### F2 触摸点位测试

* 背景：1024×600 坐标网格，间距 **64 px**（16 列 × 9 行整）
* 刻度：每 128 px 标一次坐标数字（`0 / 128 / 256 …`），网格线用暗灰
* 触摸时：
  * 每个触点在真实坐标处画**彩色准星**（十字 + 中心小方框）
  * 最多 **5 点同时**（GT911 上限），5 点分别用白/红/绿/蓝/黄 + 编号 `T1..T5`
  * 固定信息区显示：当前点数（`PTS 3`）、每点坐标（最多 5 行 `T1 600,256`）、采样计数
* 目的：验证坐标线性度、边界可达性、多点同时上报、刷新率

### F3 实时点击反馈（准星跟随）

* 手指按下瞬间（目标 **≤ 1 帧 ≈ 16.7 ms**）在触点位置出现准星，并**跟随手指实时移动**
* 抬手后准星**保留 0.5 s** 再消失，便于确认"最后一次落点"（可配）
* 信息区显示 `DOWN` / `UP` 状态与最近一次坐标
* 说明：不扩散圆环、不做拖尾（本轮未选）

### F4 模式切换

* 板载按键 `key_n`（球号 **W9**，低有效）短按：`F1 色轮播` ↔ `F2/F3 点位+反馈`
* 上电默认进 F1（一眼就能看到屏好不好）

### F5 串口遥测（协议 v3）

* `115200 8N1`，每秒 16 字节一帧
* 字段：帧头、版本 `0x03`、当前模式、屏 ID one-hot、触摸型号、点数、
  第 1 点 x/y（2+2 字节）、第 2 点 x/y、每秒采样次数、每秒错误次数
* 目的：无人值守时也能量化"跑了多少、有没有错"

### F6 触摸底层修正（本版重点）

现状：GT911 能被识别、产品 ID 读回 `0x39`、内部配置分辨率 `1024×600`、
IIC 空闲电平与 INT 电平均正常，但 `0x814E` 恒为 `0x00`（点数 0）。

本版对策（按顺序尝试，保留前一级作为回退）：

1. **按需读**：每轮只读状态字节 `0x814E`；仅当 `bit7 = 1` 时再读 26 字节点位数据并清标记
   （现在是无条件每 3.3 ms 读 26 字节并清标记，总线占用大得多）
2. **降速轮询**：把轮询周期从 ~3.3 ms 放宽到 ~10 ms（GT911 典型刷新 5–10 ms）
3. **配置兜底**：若仍不报点，按 Goodix 流程把配置表写到 `0x8047` 起，再写 `0x8100` 软复位生效
4. 保留既有能力：GT911/FT5206 自动识别、INT 上拉 + 复位时序、产品 ID/分辨率诊断

  4. 5 点并发解码
  5. 按键切模式 + 消抖
  6. UART v3 帧级（逐字节 8N1 解码）

## 4. 已知风险与前置条件

1. ⚠ **触摸尚未在硬件上验证**（0 点问题只做到"分层排除"）。F2/F3 的可见效果依赖它；
   F6 就是为它准备的对策。若 F6 全部试过仍不报点，F2/F3 只能"写得对但看不到"，
   届时会把结论与下一步（例如核对模块 FPC 上触摸供电/INT 走线）写进文档。
2. 屏上文字只有 5×7 英数点阵，字号小；大字号标题需另做字模（本版不做）。
3. J7 的第 11/20/29 针接地仍是**推定**（未用万用表复核），与显示无关但影响全屏上电检查。
