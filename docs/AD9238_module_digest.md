## 6. 如何与 FPGA 对接 (How to interface to an FPGA)

### 6.1 必须由 FPGA **驱动** 的引脚
- **ADC 采样时钟**：DEMO 中由 FPGA 内部 PLL 产生 **65 MHz** 驱动 AD 时钟（框图内标注 "65Mhz"，另一路 50MHz 给 UART）— `manual: 一. 双通道 AD 采集电压通过串口到 PC 端显示 / 功能框图 (p15–p16)`。
  **具体落在 40 针的哪一针：not found in document**（见 §3.1）。上板前必须用模块原理图确认。
- **使能 / 掉电 / 待机 / 复位引脚**：**无**（模块未引出 STBY、PWDN 等）— `manual: 6. (p9)`。

### 6.2 必须由 FPGA **采样** 的引脚
| 信号 | 位宽 | 方向 (相对 FPGA) | 说明 |
|---|---|---|---|
| `CH1_D0..CH1_D11` (AD1D0..AD1D11) | 12 | 输入 | 通道 A 数据 |
| `CH2_D0..CH2_D11` (AD2D0..AD2D11) | 12 | 输入 | 通道 B 数据 |
| `CH1_CLK` (AD1CLK) | 1 | 输入 | 通道 A 输出时钟 (DCO) |
| `CH2_CLK` (AD2CLK) | 1 | 输入 | 通道 B 输出时钟 (DCO) |
| `CH1_OTR` / `CH2_OTR` | 2 | 输入 | 超量程标志 |

合计 **28 根 FPGA IO**（24 数据 + 2 时钟 + 2 OTR），另需 +5V 与 GND。

### 6.3 推荐的 FPGA 侧采集方式
1. **源同步采集（推荐，文档明确支持）**：用 ADC 自己输出的 `CHx_CLK`（DCO）作为对应通道数据的采样时钟 —— "FPGA 端可用 AD 时钟的采样 AD 数据" `manual: 5. (p8)`，与 §3.1 一致。
2. **IO 标准**：数字侧为 **+3.3V CMOS** `manual: 1. (p5)` → Vivado 中对该组 IO 使用 **`LVCMOS33`**，且必须把所在 Bank 的 VCCO 通过板载拨码开关设成 3.3V（正点原子 达芬奇-lite 上对应 **J6 → Bank16**，见 `ATK_board_digest.md` §4）。
3. **12 位并行×2 的布线建议**：严格保持同一通道的 12 根数据线 + 该通道 DCO 在**同一 IO Bank**，走线等长；手册反复强调**板对板/短排线（≤5cm）**，杜邦线会产生噪声或电压不稳 `manual: 第五章 1 (p27)`。
4. **IDDR / ISERDES**：**not found in document**（说明书未提及，也未提供任何 IDDR/ISERDES 建议）。若要在 Xilinx 7 系上用 IDDR，属于自行设计选择，需自行做时序约束。
5. **时钟资源**：把 `CHx_CLK` 接到 **MRCC/SRCC 时钟能力引脚**并加 `create_clock` 约束 —— 此建议来自正点原子指南对同类并行接口的通用做法（见 `ATK_board_digest.md` §6），**AD9238 说明书未涉及**。
6. **DEMO 程序结构（供参考）**：顶层 `ad9238_test.v` + 3 个子模块 —— `ad.v`（AD 数据采集）、`volt_cal.v`（12-bit → 20-bit 十进制电压，去掉符号位后 11bit 换算）、`uart.v`（按 **9600** 波特率发送 26 个字符显示两路电压）；另有 Signaltap/Chipscope 观察波形 `manual: 第三章 (p15–p19)`。
