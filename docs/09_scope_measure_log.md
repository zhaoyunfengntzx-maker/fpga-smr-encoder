## 1 测量 A：ADC 捕获余量 `tPD` 实测（补 `docs/07` §1.8 判据 4 与证据索引 `tPD_meas` 行；**R7 环路延迟另测**）

**目的**：v9 时代量到 `tPD_meas ≤ 4 ns`（`DEV_STATUS` §1.27，但**没有留带游标的量化截图**）。现在 v11 把采样相位改成同相、捕获余量从 1.2–5.2 ns 提到 14–18 ns，需要**实测确认**这组数字。

| 项 | 内容 |
|---|---|
| CH1 | `J6-26`（`AD1CLK` / `ad_clk`，FPGA 球 **B18**） |
| CH2 | `J6-27`（`CH1_D0` / `ad_ch1_d[0]`），**量哪一位都行**，D0 边沿最密 |
| 输入 | AFG **1 kHz 正弦 / 8 Vpp**（想更干净就用 1 Hz 三角，数据变化慢、边沿好认） |
| 触发 | CH1 上升沿、电平 1.65 V |
| 时基 | 5 ns/div（先 20 ns/div 找到波形再放大） |
| 读法 | 用 **Δt 游标**量"CH1 上升沿 1.65 V 交叉点 → CH2 最近一次跳变"；CH2 打开**余辉**可看到"数据翻转带"，量时钟沿到**数据带前沿**（最早跳变）的距离最稳 |

- **期望**：`tPD_meas` = **2…6 ns**（AD9238 手册值）。
- **v11 下余量的算法**（写进报告用）：`ad_clk` 与 `clk_i` 同相 ⇒ 数据在 `ad_clk` 沿后 `tPD` 到达 FPGA 引脚，而捕获用的是**再下一个** `clk_i` 上升沿（= `ad_clk` 沿 + 20 ns − 约 3.0 ns 的 ODDR/OBUF 延迟 ≈ **+17 ns**）⇒ 建立余量 ≈ 17 − `tPD` − `tSU`(≈1.2 ns) ≈ **10…14 ns**（与 XDC 推导的 14–18 ns 同量级，差在计数起点）。
- **判据**：`tPD_meas ≤ 6 ns` ⇒ 与手册一致，**不需要**任何回退动作；若量到 >6 ns，记下来并在结论里注明（v11 的余量仍够，但手册一致性要说明）。
- 记录：探头衰减 10×、时基 5 ns/div、输入 1 MΩ/DC、**实测（2026-10-12 22:35，v11 生产版，CH1=`J6-26`/50 MHz、CH2=`J6-38`/`CH1_D11`/20.18 kHz，触发挂 CH2 上升沿）：`tPD_meas = 3–4 ns`** ✅（手册 2–6 ns 内、与 10-10 的 ≤4 ns 一致）⇒ 判据通过，**不需要任何回退动作**。截图 `figures/scope_tpd_v11.png`（待用户导出，**必须带两个游标**）。
- **由此确认的余量（报告可引用）**：`tPD_meas = 3.5 ns`（取 3–4 的中值）⇒ v11 建立余量 ≈ 17 − 3.5 − 1.2 = **+12.3 ns**（区间 `tPD`=2 ns → +13.8 ns、`tPD`=6 ns → +9.8 ns，即 **≈10–14 ns**），与 XDC 推导（相对 `sys_clk` 口径 +10.2…+14.8 ns）一致 ✓。

## 3 测量 C：温度与器件批次复测（R2 残留待办）

**思路（这是"用坏样本当温度探针"的实验）**：坏样本的根因是**捕获接口余量**，而 `tPD` 随温度上升 ⇒ 余量随温度变小。所以：
- 在 **v9**（余量只剩 1.2–5.2 ns）上，**加热 ADC 模块**应当让事件率上升 —— 即使当前档位在常温下是"冷点"，**加热后若冒出事件，就是温度吃掉余量的直接证据**；
- 在 **v11**（14–18 ns）上，同样加热应当**始终为 0** —— 这是修复的鲁棒性证据。

> 原计划是"常温 / 加热 / 冷却"各 30 s 窗前后对比。**2026-10-12 晚实测发现这个设计证明力不够**（冷却窗不回落，见 3.2 注），最终改用 **热态下交叉换位流 v11 → v9 → v11** 作判据（同 `_synth_work/hot_ab.ps1` 的 A/B/A 结构，只是全程保温）。

> ⚠ 加热期间**不要碰排线**；每次连续加热不超过 3 min、风口始终 ≥20 cm。

**现行寄存器已经就绪**（21:52 读回，见本文开头）：`0x0101` = 0（`inter` = 256）、`0x0102` = 0（`div` = 1）、`0x0108` = `0x4004`（`z_width` = 4）、`0x0109` = 0x0040（`abzen`）。**不需要改任何寄存器**。

| 项 | 内容 |

| 期望 | Z 周期 = `64 × 1 ms` = **64 ms**（率 **15.625 Hz** = `f_in`/64）；脉宽 = `(z_width + 1) / (1024 × f_in)` = 5 / 1024 / 1000 = **4.883 µs** |

### 6.2 测量 F：环路延迟（报告 R7「延迟未实测」；§6.3 的另一半）

- 探点：**CH1 = 输入正弦**（AFG 输出或模块输入端）、**CH2 = `J5-5`（`a_out`）**，**再把 `J5-7`（`z_out`）放上第三路**（若示波器只有两路，就先量 Z）；1 kHz、8 Vpp、时基 **200 µs/div**。
- **用 Z 当相位锚点**：Z 每 **64** 个输入周期（1 kHz ⇒ 64 ms）出一次脉冲，它在 0° 参考处上升 ⇒ 以"输入正弦过零点 → 同一时刻附近的 A 跳变沿"的时差作为环路延迟读数（`inter`=256、`div`=1 时 A 每输入周期跳 4 次，必须取与过零点同相的那一沿；不确定就先把 Z 对准，再看 A）。
- 期望与对照：预算 **≈830 ns**（报告 §6.3 / §4.3）；读数写成"实测 = ___ ns（≈ ___ 个 `clk_i` 拍，1 拍 = 20 ns）"。
