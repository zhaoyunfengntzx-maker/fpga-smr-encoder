## 1. 开机前必读：三条铁律

### 铁律一：探头地线只能接大地，绝不能夹到电路里的"数字地/浮地"

手册安全条款原文（第 iii 页）：

> **只能将探头基准导线连接到大地。**
> 将产品接地（通过电源线接地导体）。
> 请勿在潮湿环境下操作。
> 探头或测试导线连接到电压源时请勿插拔。
> 连接电流探头或断开电流探头之前请将被测电路断电。

原因：示波器的 BNC 外壳通过电源线第三脚直接连到**保护大地**。探头黑色鳄鱼夹与 BNC 外壳是同一个节点。
如果你的被测板是"浮地"（例如用隔离电源、或笔记本电池供电但没接地），把地夹夹到板上任意一点，就等于**把板上的那个点强行短接到大地**：

- 如果板上有其他点对大地存在电位差 → 大电流经探头地线流过 → **冒烟、烧板、烧探头**；
- 测量本身也会因为地环路而完全失真。

**正确做法：**
1. 被测电路的地先可靠接大地（或用隔离变压器/隔离探头）；
2. 测量时只夹**一个**地参考点，不要用多个探头地夹去夹电路里不同的"地"；
3. 需要测两个不共地的点之间的差分信号 → 用**差分探头**，或用 CH1−CH2 数学运算（两通道各自的地夹都接各自的公共地）；
4. 测市电、开关电源初级、MOSFET 漏极等**热地**电路 → 必须用隔离变压器 + 差分探头/隔离探头，绝对不能用普通无源探头。

### 铁律二：探头衰减比必须与示波器设置一致

DPO2024B 标配 **TPP0200**（200 MHz，10X 无源探头，10 MΩ）。
- 示波器默认衰减是 **10X**，与 TPP0200 匹配 → 通常不用改。
- 但如果你混用了 1X 探头、100X 探头、或有源探头，**必须在垂直菜单里改"探头设置"**，否则读数会差 10 倍/100 倍，而且垂直档位显示也会错。
- TekVPI 探头（有源/差分/电流）带编码，插上后示波器**自动识别并自动设定倍率**，这是它的优势。

### 铁律三：每次换通道/换探头，先做探头补偿

见第 3 节第 4 步。未补偿的探头会造成：
- 方波边沿"过冲带圆角"（欠补偿）或"前角尖、顶部下凹"（过补偿）；
- **上升时间测量直接失效**——你测到的可能是探头而不是电路。

## 2. DPO2024B 关键规格

| 项目 | 参数 | 使用含义 |
|---|---|---|
| 带宽（−3 dB） | **200 MHz** | 可测的最快正弦；对应最小可测上升时间 ≈ 1.75 ns |
| 计算的上升时间 | **2.1 ns** | 示波器自身上升时间。被测信号真实上升时间 tr 需满足 `tr_被测 ≥ 3 × 2.1 ≈ 6.3 ns` 才不被示波器掩盖 |
| 通道数 | **4 个模拟通道** | CH1–CH4 |
| 最大采样率 | **1 GS/s（所有通道）** | 200 MHz 信号只有 5 点/周期，测高频要用等效或正弦插值 |
| 最大记录长度 | **1 M 点（所有通道）** | 深存储，长窗口与细时间分辨率兼得 |
| 波形捕获率 | **5,000 wfm/s** | 偶发毛刺捕获能力 |
| 垂直灵敏度 | **2 mV/div – 5 V/div** | 见下方"2 mV/div 陷阱" |
| 垂直分辨率 | **8 位** | 满屏约 256 个量化级；测小信号要靠垂直档位放大 |
| 输入耦合 | **AC / DC / GND** | — |
| 输入阻抗 | **1 MΩ ±2% ∥ 11.5 pF ±2 pF** | 对高速数字电路是**容性负载**，见第 12 节 |
| 硬件带宽限制 | **20 MHz** | 每个通道可独立开 |
| 最大输入电压（1 MΩ） | **300 VRMS，峰值 ≤ ±450 V**，CAT II | 超了会损坏前端 |
| 偏置范围 | 2 mV/div–200 mV/div：±1 V；>200 mV/div–5 V/div：±25 V | 决定你能把多大的直流电平拉进屏幕 |
| 时基范围 | **2 ns/div – 100 s/div** | 200 MHz 型号为 2 ns/div 起 |
| 时基延迟范围 | −10 格 到 5000 s | Delay 模式可用范围 |
| 时基精度 | ±25 ppm | 时间测量基准 |
| 通道间偏移校正 | ±100 ns | 多通道时间对齐用 |
| 显示器 | 7 英寸（180 mm）TFT-LCD 宽屏彩色 | — |
| 尺寸/重量 | 377 × 175 × 139 mm，3.6 kg | 后面/两侧留 50 mm 散热空间 |
| 电源 | 100–240 V ±10%，50/60 Hz（115 V 时 400 Hz），最大 80 W | 三芯接地电源线必备 |
| 工作温度 | 0 – +50 °C，污染等级 2，仅室内 | 温度变化 >10 °C 要重跑 SPC |

### ⚠️ "2 mV/div 陷阱"（重要）

手册明确：**所有型号在 2 mV/div 时带宽被限制为 20 MHz**。

也就是说，垂直档位打到最灵敏的 2 mV/div，示波器自动降带宽到 20 MHz。
- 测**低速小信号**（如传感器输出、电源纹波）→ 这是好事，噪声更小；
- 测**高速小信号**（如差分对上的小摆幅时钟）→ 你会看不到真实边沿，误判为"信号很慢"。

另外 DC 增益精度分档：
- 10 mV/div – 5 V/div（偏置 0 V）：±3%
- **2 mV/div – 5 mV/div：±4%**

## 3. 标准开机流程（首次使用照做）

### 步骤 0：环境检查
- 室内、干燥、无易燃易爆气体；
- 示波器两侧和后部留 **50 mm** 以上散热空间；
- 用**三芯电源线**接到**可靠接地的插座**（这是安全与测量准确的前提，不是可选项）。

### 步骤 1：开机
- 前面板电源开关。
- 接应用模块时：**必须关机后再插拔模块**；模块插槽在前面板右上方，第二个槽在可见槽的正后方，插入时标签面**背向你**。
- **预热至少 20 分钟**再谈精度（SPC 和保证指标都要求预热）。

### 步骤 2：语言与时间（中文菜单）
```
Utility → 辅助功能页面 → (旋钮a) 配置 → 语言 → (旋钮a) 简体中文
Utility → 辅助功能页面 → 配置 → 设置日期和时间
```
注意：切换非英文语言时，**需要把随附的塑料前面板贴膜（bezel）贴上去**，因为按键丝印是英文的。

### 步骤 3：探头补偿（必做，每通道每次）

1. 把 TPP0200 探头接到 **CH1**；
2. 探头**尖端**和**黑色地夹**同时接到前面板的 **PROBE COMP** 端子（输出 0–5 V、1 kHz 方波）；
3. 按 **Default Setup**；
4. 按 **Autoset** —— 屏幕上应出现约 2.5 V 的 1 kHz 方波；
5. 为看最清楚，把垂直档位调到 **1 V/div**；
6. 观察方波顶部形状：

| 形状 | 结论 | 处理 |
|---|---|---|
| 边沿圆钝、上升沿变慢、顶部平坦但角变圆 | **欠补偿** | 用随附小螺丝刀调探头上的补偿电容 |
| 边沿有尖峰过冲、顶部前角尖后部下凹 | **过补偿** | 反向调补偿电容 |
| 标准方波 | 正确 | 完成 |

7. 调整后重复观察，直到方波方正；**换到 CH2/CH3/CH4 时重复一次**。

> **快速提示（手册原文）**：尽量使用最短的地线。长鳄鱼夹地线会引入振铃和失真，测高速边沿时必须换用探头自带的**弹簧地针**。

### 步骤 4：信号路径补偿 SPC（校准）

**何时做：**
- 环境温度变化超过 **10 °C**；
- 使用 **5 mV/div 或更灵敏**档位时，应**每周**做一次；
- 否则在灵敏档位上可能达不到保证的技术指标。

**怎么做：**
1. 预热 **≥ 20 分钟**；
2. **拔掉所有输入信号**（探头、电缆全部拆下）——输入的交流成分会降低 SPC 效果；
3. `Utility → 辅助功能页面 → 校准 → 信号路径` → 按侧面 bezel **OK** 选"补偿信号路径"；
4. 等出现完成提示，按 **Menu Off**；
5. 检查下侧状态显示为 **通过**。

> SPC **不校准探头尖端**。它只修正示波器内部因温度变化和长期漂移引起的直流误差。

### 步骤 5：验证
- 屏幕右上角应显示运行状态；
- 探头补偿波形稳定不抖动；
- 如需确认固件版本：`Utility → 辅助功能页面 → 配置 → 关于`。

## 4. 前面板与屏幕读数速查

### 菜单操作的基本逻辑（务必理解）

```
按下面板菜单键（如"采集"）
  → 屏幕下方出现主菜单项 → 按对应"下方 bezel"按钮选中
  → 屏幕右侧出现子菜单项（side menu）→ 按对应"侧面 bezel"按钮
  → 每按一次侧面按钮，选项循环切换一次
  → 再按一次下方 bezel 按钮或按 Menu Off 关闭子菜单
```

- **旋钮 a**（上方多功能旋钮）、**旋钮 b**（下方多功能旋钮）：设定数值；
- **精细（Fine）**：切换粗调/细调；
- **弹出菜单**：旋转旋钮 a 滚动，再按该按钮确认。

| 左侧基线指示 | 数学/参考波形的垂直/水平比例因子 | — |

## 5. 垂直系统：通道设置

### 建立一条模拟通道的标准动作

1. 接探头（TPP0200 或 TekVPI 探头）；
2. 按 **Default Setup**；
   - 若探头无编码，**必须在垂直菜单"探头设置"里改衰减倍率**与探头一致（默认 10X）；
3. 按对应的通道键 **1/2/3/4** 打开该通道；
4. 按 **Autoset**；
5. 调**垂直位置**和**垂直标度**，把波形放到合适大小；
6. 调**水平位置**（决定预触发/后触发比例）与**水平标度**（决定采集窗口覆盖一个边沿、一个周期、几个周期还是几千个周期）。

### 垂直菜单关键项

| 菜单项 | 说明与使用建议 |
|---|---|
| **耦合** | **DC**：能看到直流分量，测电源、测偏置、测逻辑电平必用；**AC**：隔掉直流只看交流纹波，带宽约 10 Hz 起；**GND**：断开输入内部接地，用于**找 0 V 参考线**（这是校准垂直位置的正规做法） |
| **带宽** | 开 **20 MHz 限制**可以滤掉高频噪声、看到"干净的"低频信号。测量开关电源纹波、工频干扰时必须开 |
| **微调（Vernier）** | 关 = 档位为标准序列；开 = 连续可调，此时读数会显示实际值 |
| **反相** | 波形上下翻转。CH1−CH2 差分测量 + 反相 + 相加 = 差分显示 |
| **偏置/位置** | 垂直位置旋钮。偏置范围限制见第 2 节表格 |
| **探头设置** | 衰减倍率（1X / 10X / 100X…）与单位。**这是最常被忘记、后果最严重的一项** |
| **标签** | 给通道起名，方便截图归档 |

### 通道/总线标签的输入方法

```
按通道键或 B1/B2 → 按下方 bezel「标签」
  ├─ 旋转旋钮 b 滚动预置标签列表 → 按「插入预置标签」
  ├─ 有 USB 键盘：方向键移动插入点，直接打字
  └─ 无键盘：侧/下 bezel 箭头移动插入点，旋钮 a 滚动字符表
     （A-Z a-z 0-9 _=+-!@#$%^&*()[]{}<>/~'"\|:,.?）
     按「选择/输入字符」确认一个字符；退格/删除/清除用 bezel
最后按「显示标签」→ 选「开启」
```
标签最长 **32 字符**，显示在屏幕左侧波形基线指示处。

## 6. 水平系统：时基与延迟

### 水平标度（s/div）怎么选

| 想干什么 | 时基设置思路 |
|---|---|
| 看上升沿/振铃细节 | 让**一个边沿**占满屏幕（如 2–5 ns/div） |
| 看时钟一个周期 | 一个周期占 2 格左右 |
| 看数据传输突发 | 覆盖整个 burst |
| 看低频漂移/电源启动 | 几十 ms/div 到 s/div，此时会进入 Roll 模式 |

### 水平位置：预触发与后触发

- 水平位置旋钮改变**触发点相对采集的位置**；
- **触发点左边 = 预触发数据**，**右边 = 后触发数据**；
- 排故思路（手册原文精神）：要查"毛刺从哪来的"，就把触发点设在毛刺上，让**预触发足够长**，去看毛刺发生之前发生了什么；要看"触发事件的结果"，就让**后触发足够长**。

### Delay（延迟）模式 —— 抓"触发后很久才发生的高速细节"

这是 DPO2024B 一个非常实用的能力，典型用法：
> **在每 10 ms 一次的同步脉冲上触发，然后查看同步脉冲后 6 ms 处的高速信号特征。**

- **Delay 关**：扩展点与触发点绑定，缩放围绕触发点进行；
- **Delay 开**：扩展点固定在屏幕中央，触发点可移出屏幕（此时有触发标记指向它的方向）。顺时针转水平位置 = 增加延迟 = 触发点左移；再用**水平标度**围绕屏幕中央的兴趣区放大。

菜单路径：`采集 → 延迟 开|关`

### Roll（滚动）模式

- 类似**带状图记录仪**，适合低频信号，不必等整条记录采完就能看到点；
- 启用条件：**触发模式 = 自动** 且 **水平标度 ≤ 40 ms/div**；
- **以下情况自动禁用**：切到"平均"采集模式、使用数学波形、打开总线、切到"正常"触发、水平标度 ≤ 20 ms/div；
- Roll 模式下**缩放禁用**；按"运行/停止"停止。

## 7. 采集系统：模式、记录长度、FilterVu

### 采集的四个要素

| 概念 | 由什么控制 | 含义 |
|---|---|---|
| **采样间隔** | 水平标度旋钮 或 记录长度 | 记录点之间的时间 |
| **记录长度** | 采集菜单 | 采样点个数（100 k / 1.00 M；慢时基下还有 125 k / 1.25 M） |
| **触发点** | 触发系统 | 记录中的零时刻，画成橙色 T |
| **水平位置** | 水平位置旋钮 | Delay 开 = 触发点到扩展点的时间；正 = 采触发之后，负 = 采触发之前 |
| **扩展点** | 随水平标度改变 | 水平缩放的中心，橙色三角 |

### 三种采集模式

| 模式 | 原理 | 什么时候用 |
|---|---|---|
| **取样（默认前景）** | 每个采集间隔取**第一个**样点 | 常规观察，波形看着"自然" |
| **峰值检测（FilterVu 毛刺捕获背景）** | 取相邻两个间隔的**最高点和最低点** | **抓毛刺**——可捕获窄至 **5 ns** 的脉冲；高速时基下不可用 |
| **平均** | 每个记录点对 N 次采集求平均 | 信号**重复**、噪声**随机**（与触发不相关），需要提高垂直精度。N 可选 2/4/8/16/32/64/128/256/512 |

> **平均模式的代价**：它假定信号完全重复。如果信号本身在变化（如串行数据、跳变状态），平均会把真实变化也平均掉。

### FilterVu：一边降噪一边抓毛刺（DPO2024B 的招牌功能）

原理：在**毛刺捕获背景波形**上叠加一个**滤波后的前景波形**。
- 前景：可变低通滤波器，把截止频率调低 → 波形干净。调到最小带宽时，导致假波的高频分量**通过不到 1%**；
- 背景：峰值检测 min/max 采样，保留完整带宽的细节；滤波后背景波形会**变色**，亮度可单独调；
- 屏幕上**右上角始终显示截止频率**（−3 dB 点）。

**怎么选（手册原文对比）：**

| 需求 | 选 FilterVu | 选带宽限制 | 选平均 |
|---|---|---|---|
| 需要比带宽限制更细的频率调节 | ✅ | | |
| 所有通道滤到同一频率 | ✅ | | |
| 非重复 / 单次信号 | ✅ | ✅ | |
| 只滤一个通道 | | ✅ | |
| **要在滤波后的信号上触发** | | ✅ | |
| 信号重复 + 噪声随机 + 要提垂直精度 | | | ✅ |

**其他要点：**
- FilterVu **不影响触发**——想降低触发抖动要用**带宽限制**或**触发耦合**；
- FilterVu **不能与平均模式同时使用**（FilterVu + 带宽限制可以）；
- 保存文件时可选完整分辨率或降低分辨率；**滤波时只有降低分辨率的波形才保证滤到所选频率**；毛刺捕获开启时保存的文件同时含前景和背景数据；
- 测量：未滤波时大多数测量跑在前景上，**最小值/最大值/峰峰值跑在毛刺捕获背景上**；一旦滤波，**所有测量都跑在滤波后的波形上**；
- 搜索使用毛刺捕获背景（可用时）；
- **串行总线解码使用完整分辨率（前景）波形**，所以滤波开启时解码用的波形**可能并未滤到所选频率**——这是 I²C/SPI 解码偶发误码的一个隐藏原因。

**操作：**
```
按 FilterVu
  → 旋钮 a 逆时针调低「噪声滤波器（前景）」截止频率（默认 = 满带宽）
  → 按「毛刺捕获背景」开|关
  → 背景开时，旋钮 b 调背景亮度（仅滤波时可调）
```

### 记录长度怎么选

```
采集 → 记录长度 → 100k 或 1.00M（慢时基下另有 125k / 1.25M）
```
- 长记录（1 M 点）→ 能同时看"很长的活动窗口"和"精细的时间分辨率"，这是 DPO2000B 的标配优势；
- 代价：处理慢、波形更新率下降。

## 8. 触发系统：全类型详解

### 触发概念

- **触发事件**在记录中建立**时间基准点**，所有数据以它为零点定位；
- 示波器始终保留足够的样点填满**预触发**部分（屏幕触发点左边），触发后继续采集填**后触发**部分；
- 识别到触发后，**采集完成且释抑期满前不再接受新触发**。

### 触发模式

| 模式 | 行为 | 注意 |
|---|---|---|
| **正常（Normal）** | **只在触发时采集**。没触发就保留上一次的波形记录；从没有过则无显示 | 抓偶发事件用这个，但要配合"单次" |
| **自动（Auto）** | 没触发也会采（计时器超时后强制触发）。没有有效触发时波形会在屏上滚动；一旦有有效触发就稳定 | **默认模式**，调试时先用它确认信号存在 |
| **单次（Single）** | 单次采集，并把触发模式设为**正常** | 抓单次事件 |

**强制触发**：按前面板"强制触发"按钮，立即产生一次触发。信号不来时用它确认通道/时基是否正确。

### 触发释抑（Holdoff）

调整释抑可以让示波器**跳过不想要的触发事件**，从而获得稳定显示。释抑期间示波器不识别新触发。
典型场景：一串突发脉冲中只想稳定在每串的第一个脉冲上 —— 把释抑设为略小于串周期。

### 触发耦合

决定信号哪一部分进入触发电路：
- **边沿触发支持全部耦合**：DC、低频抑制、高频抑制、噪声抑制；
- **其他所有触发类型只用 DC 耦合**；
- **低频抑制截止 65 kHz**，**高频抑制截止 85 kHz**。

排故用法：
- 电源纹波导致误触发 → 用**低频抑制**（滤掉 50 Hz/100 Hz 工频）；
- 高频噪声导致误触发 → 用**高频抑制**；
- 抖动导致触发不稳 → 用**噪声抑制**。

### 触发类型全表

| 类型 | 触发条件 | 典型用途 |
|---|---|---|
| **边沿** | 在指定斜率上穿越指定电平。最简单最常用，模拟/数字信号均可 | 时钟、一般信号 |
| **脉冲宽度** | 小于/大于/等于/不等于指定时间的脉冲，正脉冲或负脉冲 | 数字信号：抓异常宽/窄脉冲 |
| **欠幅脉冲（Runt）** | 脉冲幅度越过第一个阈值，但在越过第二个阈值前又回落 | 数字信号：抓"没到满幅"的坏电平 |
| **逻辑** | 所有通道都进入指定状态时触发。旋钮 a 选通道，侧 bezel 设 **H / L / X（无关）**。按"时钟"侧 bezel 可启用**定时（状态）触发**，最多一个时钟通道；把时钟通道设为 H/L/X 即可关掉定时触发。非定时触发默认在条件**变真**时触发，也可设为**变假**或**时间限定**触发 | 地址/数据总线组合条件；MSO 下最多 20 通道（4 模拟 + 16 数字） |
| **建立与保持** | 逻辑数据相对时钟沿的建立/保持时间违例时触发。建立 = 时钟沿**前**数据稳定的时间；保持 = 时钟沿**后**数据稳定的时间 | **查 FPGA 到外设的时序违例**，MSO 下最多 20 通道 |
| **上升/下降时间** | 脉冲边沿以快于或慢于指定时间的速率在两个阈值间移动时触发 | 查边沿变慢、驱动能力不足 |
| **视频** | 触发复合视频的指定场或行。支持 NTSC / PAL / SECAM，支持 Macrovision | 视频信号 |
| **总线** | 见第 10 节。I²C/SPI 需 **DPO2EMBD**；CAN/LIN 需 **DPO2AUTO**；RS-232/422/485/UART 需 **DPO2COMP**；并行总线需 MSO2000B 系列 | 协议级调试 |

### 总线触发的数据匹配方式（I²C / SPI / CAN / LIN）

- **滚动窗口字节匹配**：定义要匹配的字节数 N，示波器在包内以一次滑动一个字节的窗口查找所有匹配字节。
  例：N=1 → 尝试匹配第 1、2、3… 个字节；N=2 → 尝试匹配 (1,2)、(2,3)、(3,4)…；找到即触发。
- **特定字节匹配（非滚动窗口，用于包内固定位置）**：
  - I²C / SPI：输入字节数，用**随意（X）屏蔽**不关心的字节；
  - I²C：在"地址/数据"上触发时，把地址设为 **X** 即可屏蔽地址，数据从第一个字节开始匹配，不使用滚动窗口；
  - CAN：标识符和数据**总是从第一个字节开始匹配**，支持限定符 **=、≠、<、>、≥、≤**，不使用滚动窗口；
  - **并行总线**：**只用模拟通道或只用数字通道**能获得最佳触发性能。

### 检查触发设置

看屏幕**底部触发读数**：源、斜率、电平、**频率**。
例：触发源 = 信道 1，触发沿 = 上升，触发电平 = 1.84 V，频率 = 68.901 Hz。

### 开始/停止采集

- **运行/停止**：连续采集，再按一次停止；
- **单次**：单次采集（并把触发模式设为正常）。

## 9. 测量、光标、数学与 FFT

### 自动测量

- 按 **测量** 键进入；屏幕上**最多同时显示 4 个测量值**；
- 若数值位置出现**限幅/削顶符号**，说明波形有部分在屏幕外 → 旋转垂直标度/位置把波形拉进屏内，测量才有效；
- 测量与 FilterVu 的关系：未滤波时 min/max/峰峰值跑在毛刺捕获背景上，其余跑前景；**滤波后全部跑在滤波波形上**。

### 光标

按 **光标** 键循环三态：
1. **关**；
2. **两条垂直光标**（附着在所选波形上）→ 测时间差 Δt、1/Δt（频率）；
3. **四条光标**（两垂直 + 两水平，不附着波形）→ 同时测 Δt 和 ΔV。

按 **选择** 键：链接/取消链接光标；4 光标时切换垂直或水平为活动对。

> 用光标测上升时间时，务必先确认探头补偿正确且用短地线，否则你测到的是探头。

### 数学波形（按 M 键）

- **双波形运算**：加、减、乘、除；
- **FFT**：看频谱。测量读数会切换为频率/幅度（而非时间/幅度）；
- 数学波形可被 FilterVu 滤波，但**没有毛刺捕获背景**；
- 注意：打开数学波形会**禁用 Roll 模式**。

### 参考波形（按 R 键）

- 把当前波形存为参考，用于前后对比；
- 参考波形**可被滤波**（与当前相同的噪声滤波频率会应用到它），也**有毛刺捕获背景**；
- 参考波形**始终以完整分辨率保存**（与保存到文件不同，这里没有降分辨率选项）。

### Wave Inspector（深存储的浏览利器）

- **平移**旋钮：在 1 M 点记录里滚动；
- **缩放**：上下分屏，上屏看全貌，下屏看细节（手册快速提示：上屏看多个周期，下屏看单个周期）；
- **播放/暂停**：自动平移，速度由平移旋钮控制；
- **标记**：设置/清除标记，用 ← / → 在标记间跳转；
- **搜索**（按"搜索"键）：按条件自动搜索并放置标记。搜索使用**毛刺捕获背景**（可用时），能更好地找尖峰和异常。

## 10. 串行总线解码（DPO2EMBD：I²C / SPI）

> 你有 `dpo2024b-free-dpo2embd` 文档 —— **DPO2EMBD 是 I²C 和 SPI** 应用模块。
> CAN/LIN 需要 DPO2AUTO，RS-232/422/485/UART 需要 DPO2COMP。DPO2024B 是 DPO 系列，**没有数字通道**，所以并行总线功能不可用。

### 两步使用总线

1. 按 **B1 或 B2**，输入要触发的总线参数（**不触发也能显示总线信息**）；
2. 按 **触发 Menu**，输入触发参数。

B1 和 B2 可独立使用，同时看两条不同总线。
总线源可以是通道 1–4 的**任意组合**。

### 总线参数设置流程

```
按 B1/B2
  → 总线（旋钮 a 滚动：并行 / I2C / SPI / CAN / RS-232 / LIN）
  → 定义输入（分配信号到通道）
  → 阈值
  → B1 标签
  → 总线显示（十六进制 / 二进制 / ASCII（仅 RS-232））
  → 事件表（开 = 显示带时间戳的包列表）
  → 储存事件表（保存为 .csv）
```

### 阈值预置值

| 预置 | 对应逻辑 |
|---|---|
| **1.4 V** | TTL |
| **2.5 V** | 5.0 V CMOS |
| **1.65 V** | 3.3 V CMOS |
| **1.25 V** | 2.5 V CMOS |
| **−1.3 V** | ECL |
| **3.7 V** | PECL |
| **0 V** | — |

也可逐位/逐通道自定义：按"选择"侧 bezel，旋钮 a 选位或通道，旋钮 b 设电压（高于该电平为高，低于为低）。

### I²C 参数

1. **定义输入**：把 SCLK 和 SDA 分配到任意通道；
2. **地址中包含 R/W**：
   - **是** → 7 位地址显示为 **8 位**，其中**第 8 位（LSB）是 R/~W 位**；
   - **否** → 7 位地址显示 7 位，10 位地址显示 10 位；
   - 10 位地址始终显示为 **11 位**：前 2 位是地址的 2 个 MSB，接着 1 位是 R/~W，后面 8 位是地址的 8 个 LSB；
   - **物理层上 10 位 I²C 地址前的 5 位 `11110` 编码永远不会出现在地址读数里**。

### SPI 参数

1. **定义输入**：**成帧** = **SS（Slave Select）** 或 **空闲时间**；把 SCLK、SS、MOSI、MISO 分配到任意通道；
2. **配置**：
   - **SCLK**：选择与总线匹配的时钟边沿；
   - **SS / MOSI / MISO**：设为 **为高电平** 或 **为低电平**（"为高电平"= 信号大于阈值时有效；"为低电平"= 小于阈值时有效）；
   - **字大小**：旋钮 a 设置（如 8 位）；
   - **位顺序**：**MS 先** 或 **LS 先**。

### 位序 —— 最容易搞错的坑（手册原文要点）

**物理层**（模拟通道 1–4 的实际波形轨迹）**总是把先发送的位画在左边**。

各总线的实际发送顺序：
- **I²C 和 CAN：先发 MSB**；
- **SPI：不规定位顺序**；
- **RS-232 和 LIN：先发 LSB**。

但**解码光迹和事件表中，示波器一律 MSB 在左、LSB 在右**。所以要"翻转"读数。

手册例子：RS-232 开始位之后的采样为 高,高,高,低,高,低,低,高。
- RS-232 用**高 = 0、低 = 1** → 实际值 `0001 0110`；
- 解码先显示 MSB，示波器**反转位序**显示 `0110 1000`；
- 十六进制显示为 **68**，ASCII 显示为 **h**。

**事件表行数规则：**
- I²C / SPI / CAN / LIN：**每个包一行**；
- RS-232：**包 = 关**时每 7 或 8 位字节一行，**包 = 开**时每个包一行；
- 定时并行总线：每个时钟沿一行；非定时并行总线：任一位变化时一行。

**用 ASCII 模式解码 RS-232 时，一个大点表示该值超出可打印 ASCII 范围。**

## 11. 保存、调用与数据导出

### 保存

- 前面板 **Save** 键：**立即按当前 Save/Recall 参数保存**（不弹菜单）；
- **Save/Recall 菜单**：设置保存内容（屏幕图像、波形数据、设置）与格式；
- **储存事件表**：把总线事件表存为 `.csv`；
- 滤波 + 毛刺捕获开启时，保存的波形文件**同时包含前景和背景数据**；
- 完整分辨率 vs 降低分辨率：滤波时**只有降低分辨率的波形保证滤到所选频率**；完整分辨率波形的频率会记录在保存的文件里。

### 接口

| 接口 | 位置 | 用途 |
|---|---|---|
| **USB 2.0 HOST** | 前面板 | U 盘（存数据）、USB 键盘（输标签），可热插拔 |
| **USB 2.0 DEVICE** | 后面板 | 连 PC（USBTMC，配合 VISA 驱动）或 PictBridge 打印机 |
| **LAN RJ-45 10/100Base-T** | 后面板 | **需选配 DPO2CONN 模块**；联网与 e*Scope 网页控制 |
| **视频输出 DB-15** | 后面板 | **需选配 DPO2CONN**，把屏幕导出到显示器/投影仪 |

### PC 连接设置（Utility → 辅助功能页面 → I/O）

## 12. 【重点】FPGA / AD9238 测量实战

针对你手上的达芬奇 Lite + 双 AD9238 + TW28 项目，这一节是最实用的。

### 12.1 通道分配建议

| 通道 | 建议接什么 |
|---|---|
| **CH1** | 被测时钟（如 FPGA 输出到 ADC 的采样时钟，或 ADC 的 DCO） |
| **CH2** | 数据线 / 触发源信号（如 frame valid、sync） |
| **CH3** | 参考信号（DAC 输出、模拟输入） |
| **CH4** | 模拟输入本身（AD9238 的 AIN） |
| **Aux In** | 外部触发输入（触发电平可在 +12.5 V ~ −12.5 V 调） |

### 12.2 测量顺序（每一步都有理由）

1. **先确认地**：确认板和示波器共地，探头地夹只夹一个板地点；
2. **探头补偿**：CH1–CH4 全部做一遍（第 3 节）；
3. **`Utility → 配置 → 关于`** 确认 DPO2EMBD 模块在不在、试用期剩多少天（**试用期从首次开机开始 30 天**）；
4. **接时钟，按 Default Setup → Autoset**，确认能看到时钟；
5. **用触发读数行核对频率**：显示值应与你 RTL 里期望的时钟频率一致（时基精度 ±25 ppm）。不一致先查 PLL/MMCM 配置，别急着怪示波器；
6. **量上升时间**：`2 ns/div`，单次或平均模式，用**弹簧地针**，测 10%–90%；
   - ⚠️ 你的示波器自身 tr = **2.1 ns**。若测得约 2–3 ns，说明真实边沿比示波器快，**你测的是示波器，不是电路**。要得到可信值需要 `tr_被测 ≥ 6.3 ns`；
7. **量建立/保持**：用 CH1 当时钟、CH2 当数据，开**建立与保持触发**，直接抓违例（比反复看波形高效得多）；
8. **抓毛刺/亚稳态**：用**脉冲宽度触发**抓过窄或过宽的脉冲；用 **FilterVu**（毛刺捕获背景）保留毛刺同时得到干净前景；
9. **测小信号（ADC 满量程/小信号输入）**：垂直档位放大到波形占满屏幕（**不要**打到 2 mV/div，那会把带宽压到 20 MHz）；
10. **I²C/SPI 配置通信排故**：按 B1 → 总线 = I2C/SPI → 分配 SCLK/SDA（或 SCLK/SS/MOSI/MISO）→ 阈值设 1.65 V（3.3 V CMOS）或 1.4 V（TTL）→ 总线显示十六进制 → 事件表开 → 抓"丢失确认"或"停止"；
11. **归档**：Save 键存屏幕图（PNG）+ 事件表存 CSV。

### 12.3 无源探头的容性负载 —— 你的项目一定会遇到

TPP0200 的输入阻抗是 **10 MΩ ∥ 约 11.5 pF**（1:10 探头把 11.5 pF 折算到被测端约 1 pF 量级，但仍可观）。

对一个 50 MHz 的 FPGA 时钟：
```
Xc = 1 / (2π × 50e6 × 1e-12) ≈ 3.2 kΩ
```
在 3.3 V 逻辑、几十 Ω 源阻抗的走线上，这个负载足以：
- 让上升沿变慢；
- 引入振铃；
- 在最坏情况下让边沿"塌边"。

**这就是为什么接上探头后电路行为会变。** 处理办法：
1. 测高速边沿**必须**用探头自带的**短地弹簧**，绝不能挂长鳄鱼夹；
2. 优先在**驱动端**而不是接收端测；
3. 需要真实观察时换**有源探头**（TekVPI 接口支持，自动定标和确定单位）或 FET 探头；
4. 若只是确认逻辑高低，可在垂直菜单开 **20 MHz 带宽限制**，把探头引入的高频振铃滤掉。

### 12.4 采样率与混叠的边界

1 GS/s、200 MHz 带宽 → 200 MHz 正弦只有 **5 点/周期**。
- 观察周期性信号形状时，示波器会用正弦插值"美化"，但那**不是真实波形**；
- 要确认沿的细节，必须**放大时基**让边沿占更多点；
- **1 GS/s 只能无混叠地表示 500 MHz 以内的信号**，而前端带宽是 200 MHz —— 所以带宽限制是有效的抗混叠保护，但如果你测的是含有 >200 MHz 成分的快沿，**混叠仍然可能发生**（前沿把高频"折"回低频）。看到"不合理的低频抖动"先怀疑混叠。

### 12.5 双通道差分测量（无差分探头时的替代法）

要测 AD9238 差分输入的正负端摆幅，而手头没有差分探头时：
1. CH1 接 V+，CH2 接 V−；
2. 两个通道**都用 10X、同样的 V/div、同样的耦合**；
3. 数学波形选 **CH1 − CH2**；
4. ⚠️ 这**不是**真正的差分测量：两个探头地夹都接到板地，共模抑制完全依赖两个通道的增益/偏置匹配（手册只保证 ±3%~4% DC 增益精度）。共模电压高时不可用，需要差分探头。

## 13. 常见错误与故障排查

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 看到波形但幅度差 10 倍/100 倍 | **探头衰减比设置与探头不符** | 通道菜单 → 探头设置 → 改成正确倍率 |
| 方波边沿圆钝或顶部下凹 | **探头未补偿** | 做探头补偿（第 3 节步骤 3） |
| 根本没波形，屏幕空白 | 通道未开 / 挡位太偏 / 触发没来 | 按 Default Setup → Autoset；确认通道键亮；看触发状态读数 |
| 触发状态一直显示「触发?」 | 触发电平不在信号范围内 / 用了"正常"模式但无触发 | 按触发电平旋钮（自动 50%），或临时切「自动」模式确认信号存在 |
| 波形在屏上"跑"、不同步 | 处在自动模式且无有效触发（强制触发） | 调触发电平/斜率；用"正常"模式 |
| 波形抖动、触发不稳 | 触发信号上有噪声 | 触发耦合改**噪声抑制 / 高频抑制 / 低频抑制**，或先开 20 MHz 带宽限制 |
| 测得的上升时间总是 ~2 ns | **你测的是示波器自身的上升时间（2.1 ns）** | 被测信号需要 tr ≥ 6.3 ns 才能准确测 |
| 小信号噪声特别大 | 垂直档位太大（每格 V 数太大） | 缩小 V/div 让波形占满屏幕；但**不要用 2 mV/div 去测高速信号** |
| 高速小信号看不到快沿 | 打在 2 mV/div，带宽被限制为 20 MHz | 提高 V/div 档位 |
| 上了探头电路就不正常 | 探头的容性负载 | 用短地弹簧；在驱动端测；换有源探头 |
| 电源纹波测不准 | 没开带宽限制，且地线太长 | 垂直菜单开 **20 MHz 带宽限制**，用弹簧地针 |
| 平均模式看不到变化 | 信号不重复，被平均掉了 | 关平均，改用 FilterVu 或取样模式 |
| Roll 模式打不开 | 触发模式不是"自动"，或时基快于 40 ms/div，或开了数学/总线 | 按第 6 节条件检查 |
| I²C/SPI 解码偶发错 | 阈值不对 / 位序设错 / **滤波后解码用的是未滤波的完整分辨率波形** | 核对阈值与 3.3 V/5 V 电平；核对 MS 先/LS 先；必要时关滤波 |
| 提示模块功能不可用 | 对应应用模块未安装 / **30 天试用期已过** | `Utility → 配置 → 关于` 查看 |
| 灵敏档位下指标不达标 | 很久没做 SPC，或温度变化 >10 °C | 做 SPC（第 3 节步骤 4） |
| 屏幕上有削顶符号替代测量值 | 波形有部分在屏幕外 | 调垂直标度/位置把波形拉回屏内 |

## 14. 维护：SPC、固件、清洁

### SPC（信号路径补偿）
- **触发条件**：环境温度变化 > 10 °C；使用 5 mV/div 或更灵敏档位时**每周**一次；
- **要求**：预热 ≥ 20 分钟 + **拆除所有输入信号**；
- **路径**：`Utility → 辅助功能页面 → 校准 → 信号路径`；
- **验证**：下侧状态显示"通过"；
- **注意**：SPC **不校准探头尖端**。

### 固件升级
见第 11 节。**关键：安装过程绝不能断电/拔 U 盘。**

### 清洁
- 灰尘：**无绒布**轻擦；
- 较脏：**微湿软布**或 **75% 异丙醇**溶液；
- **禁止**研磨性清洁剂或化学清洁剂；
- **避免刮伤显示屏的滤光材料**（显示屏表面很软，别用纸巾或干布用力擦）。

### 应用模块
- 30 天免费试用**从首次开机开始计时**；
- 查看剩余时间：`Utility → 辅助功能页面 → (旋钮a) 配置 → 关于`；
- 最多装 2 个模块，插槽在前面板上方右侧（第二个槽在可见槽正后方，插入时标签面朝外）；
- **插拔模块必须关机**。
