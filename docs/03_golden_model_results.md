## 1. 模型做了什么

与 RTL **逐位一致**的定点仿真，覆盖从模拟前端到角度输出的完整链路：

```
理想 sin/cos
  → 误差注入（直流偏置 / 幅值失衡 / 正交相位误差 / 二次谐波 / ADC 噪声）
  → AD9238 12bit 量化（偏移二进制，±2048）
  → 去偏置并提升到 Q1.15
  → 抽取平均（抽取率 4）
  → sc_correct 六参数校正 + 数字 AGC        【对应 rtl/sc_correct.v】
  → cordic_atan2 16bit 全流水角度            【对应 rtl/cordic_atan2.v】
  → 误差统计（与抽取窗口中心的真实电角度比较）
```

**关键工程细节（都已在模型里量化验证）：**
- 16×16 乘法用 `$signed()` 语义，`>>> 15` 为算术右移
- CORDIC 内部 x/y 位宽 = 输入 + 3，角度累加器 ZW = AW+4 = 20
- 移位一律**向零截断**（不是 Verilog `>>>` 的向下取整）
- 输出 ZW→AW 时**加半个 LSB 四舍五入**
- 结果按 16 位有符号饱和

## 2. 主结果：六参数闭式标定的误差抑制能力

单位：**一个 sin/cos 输入周期内的电角度误差（度）**

| 工况 | 校正前 max | 校正后 max | 校正前 RMS | 校正后 RMS | 圆度前 (%) | 圆度后 (%) | 改善倍数 |
|---|---|---|---|---|---|---|---|
| **A** 理想信号（仅 12bit 量化） | 0.0165 | 0.0165 | 0.0060 | 0.0055 | 0.055 | 0.056 | — |
| **B** 直流偏置 ±800 LSB | 13.9856 | **0.0165** | 9.8610 | 0.0063 | 47.638 | 0.061 | 848× |
| **C** 幅值失衡 1.25× | 6.3885 | **0.0165** | 4.5086 | 0.0061 | 22.151 | 0.055 | 387× |
| **D** 正交相位误差 5° | 5.0043 | **0.0220** | 3.0632 | 0.0066 | 8.752 | 0.062 | 227× |
| **E** 三类误差叠加 | 20.9839 | **0.0165** | 10.0861 | 0.0060 | 56.108 | 0.056 | **1273×** |
| **F** E + 二次谐波 0.5% + ADC 噪声 1 LSB | 21.0773 | 0.3571 | 10.1577 | 0.1855 | 55.699 | 1.163 | 59× |
| **G** 20% 满量程小信号 + 误差 | 18.6603 | 0.3131 | 8.5855 | 0.0732 | 49.680 | 0.940 | 60× |

**"圆度"** = `(r_max − r_min) / r_mean × 100%`，衡量李萨如图偏离正圆的程度。这一列是**现场演示时最直观的证据**：校正前是 56% 的斜椭圆，校正后是 0.06% 的正圆。

### 2.1 三条可直接写入报告的结论

1. **对可标定误差的抑制能力**：偏置 + 幅值失衡 + 正交误差的复合畸变下，电角度误差从 **20.98° 降至 0.0165°**，改善 **1273 倍**。
   此时残余误差（0.0165° = 3 LSB；可标定工况里最差的 D 为 0.0220° = 4 LSB）已落在 **16bit 角度输出的量化底噪**（1 LSB = 0.0055°）附近 —— **瓶颈已不在标定算法，而在角度字长与 ADC 前端。**

2. **残余误差的主导项**（这是下一阶段的优化方向，写进"展望"而不是"不足"）：
   - **未补偿的二次谐波**：0.5% 的 2 次谐波 → 0.357° 残余（工况 F）
   - **12bit ADC 量化噪声**：小信号（20% 满量程）时 → 0.313° 残余（工况 G）

3. **换算到机械角**：16bit 电角度 × 64 极对磁环 ⇒ 机械分辨率 **0.309 arcsec**；
   复合畸变工况下机械角误差 **20.1 arcsec**（= 0.0056°），优于常见 17bit 光电编码器的指标口径。

## 3. CORDIC 独立精度扫描

这一节有两组数字，**它们来自两个不同保真度的模型，必须分清**：

### 3.1 RTL 保真模型（**推荐引用这一组**）—— `model/cordic_model.py`

逐位复刻 `rtl/cordic_atan2.v` 的定点语义，**包括 RTL 里 x/y 内部额外保留的 FEXT=4 位小数**，1/16 LSB 细网格、全圆 **1048576 点**、幅度 A=32767：

```
max |err| = 0.9375 LSB = 0.005150° = 18.54 arcsec      （目标 ≤ 1 LSB = 0.0054932°，裕量 6.25%）
RMS |err| = 0.3229 LSB = 0.001774°
均值      = +0.001 LSB                                   （无系统性偏置）
八个正交/45° 精确边界点误差 = 0 LSB
八个边界 ±0.25° 密集扫描（2001 点/边界）max = 0.7849 LSB
mag = 32770…32771，相对真实模长误差 +0.0076%…+0.0111%
```

**达标靠三个措施**（每一个都是实测出来的，不是猜的）：

| 措施 | 效果 |
|---|---|
| **NITER 取 17**（不是 16） | 16 级时残余 `atan(2^-15)` = 0.318 LSB，叠加输出量化 ±0.5 LSB 与表取整误差后下限必然 >1 LSB，实测 1.19 |
| **x/y 内部加 FEXT=4 位小数**再向零截断 | 1.50 → 0.94 LSB |
| **输出前加半个 LSB 四舍五入** | 消除 −0.5 LSB 的截断偏置 |

对照数据（同一 1/16 LSB 网格）：

| 配置 | 最坏误差 |
|---|---|
| NITER=16 + 契约原印表 | 1.3125 LSB |
| NITER=16 + 定义式表 | 1.1875 LSB |
| NITER=17 + 契约原印表 | 1.1875 LSB |
| **NITER=17 + 定义式表 + FEXT=4 + 四舍五入（最终采用）** | **0.9375 LSB ✔** |

> 契约早期手抄的 ATAN 表第 2/4/8 项（40881/10416/651）与定义式 `round(atan(2^-i)·2^20/2π)` 不符（应为 40884/10417/652），三项合计引入约 **−0.38 LSB** 系统偏置。**已修正契约表**，RTL 用 `parameter ATAN_SRC` 选择，最终采用 `ATAN_SRC=1`（定义式值）。

### 3.2 全链路黄金模型（较保守，便于与主链路对账）—— `model/golden_model.py`

`golden_model.py` 里的 CORDIC 为了保持与主链路一致，**内部 x/y 只用整数（没有 FEXT 小数位）**，所以结果略保守，**65536 点全周扫描**、与连续理想角比较：

```
max |err| = 1.000 LSB = 0.005493° = 19.78 arcsec
RMS |err| = 0.4418 LSB = 0.002427°
8 个正交点误差全部为 +0.0000
```

**两组数字都满足 ≤1 LSB 的验收线**，差异（0.9375 vs 1.000 LSB）来自 FEXT 小数位，已经定位清楚。
**报告里建议这样写**：*"RTL 保真模型最坏 0.9375 LSB；全链路黄金模型因内部 x/y 未保留小数位而略保守，为 1.000 LSB。两者差值已定位到 FEXT 位宽，模型与实现一致。"* —— 这句话本身就是"模型和 RTL 对得上"的证据。

### 3.3 通过模型发现并修正的**四个**真实缺陷（写入报告的"工程细节"）

| # | 缺陷 | 现象 | 修正 | 修正后效果 |
|---|---|---|---|---|
| 1 | **CORDIC 象限折叠写反** | 全周出现 **180° 固定误差**（实测 100°/135°/170° 分别偏 −110°/−145°/−180°） | 第二象限必须映射为 `(x,y) → (+y, −x)`，第三象限 `→ (−y, +x)` | 全周误差正常，8 个正交点误差为 0 |
| 2 | **`>>>` 对负数是向下取整** | 输出存在**系统性 −1 LSB 偏置**（0° 与 270° 处恒定 −0.0055°） | 显式实现**向零截断**；输出前加半个 LSB 再右移 | RMS 从 **0.597 → 0.3229 LSB**（RTL 保真模型） |
| 3 | **契约手抄的 ATAN 表有 3 项不符定义式** | 引入约 **−0.38 LSB** 的系统偏置 | 按 `round(atan(2^-i)·2^20/2π)` 重算（40884/10417/652） | NITER=17 下最坏误差 1.1875 → 0.9375 LSB |
| 4 | **照抄 TW28 推荐的"重滤波"档会让 PI 环发散** | 用旧积分值 `I[n]` 时 Jury 判据要求 `Ki < Kp`，而 TW28 heavy 档 kp=6/ki=3 对应 `Kp=1/256 < Ki=1/16` → **发散** | 改用本拍更新后的 `I[n+1]`（只差一个采样周期相位），判据变为 `0<Kp<2、Ki>0、Ki<4−2Kp` | kp=0…7 × ki=1…3 **全部 21 组稳定**，恒速滞后 0…0.0014° |

> 这四条是**真实的、可复现的、有数字支撑的工程经验**。尤其是第 4 条 —— 它证明团队没有"照着数据手册抄参数"，而是**自己把控制环的稳定性重推了一遍，并发现参考实现的推荐值在本实现下会发散**。在报告里写出来，比罗列十张架构图更能体现"专业性"。
>
> 第 4 条的完整 Jury 推导见 `rtl/loop_filter.v` 头注释；实测表见 `docs/01` §3.4。

## 4. 过采样抽取的等效位数增益

| 抽取率 | 白噪声下的 ENOB 增益 |
|---|---|
| 1 | 0.00 bit |
| 2 | 0.50 bit |
| **4**（本设计默认） | **1.00 bit** |
| 8 | 1.50 bit |
| 16 | 2.00 bit |

**结论**：12bit ADC 在抽取率 4 时，理论等效位数约 **13bit**；实际受前端噪声与孔径抖动限制，需以实测为准。
