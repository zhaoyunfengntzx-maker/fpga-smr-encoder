# 基线总表（v62 → v90）

本文件是全部位流基线的**唯一汇总口径**。每个数字都能在
[`deliverables/data/`](../deliverables/data/) 下找到对应报告或日志；
逐条哈希见 [`deliverables/data/SHA256SUMS.txt`](../deliverables/data/SHA256SUMS.txt)（323 条）。

**当前交付基线是 v90（2026-11-04）**：生产 `enc_top_v90.bit` 与显示 `enc_top_disp_v90.bit`。
v74（生产）与 v85 / v89（显示）均为历史版本，只在血缘追溯时引用。

## 0. 口径

| 标记 | 含义 |
|---|---|
| `[构建签核]` | Vivado 实现完成，时序 / DRC / 布线报告齐全，位流可下载 |
| `[上板]` | 已下载到真实板卡并有人工读数 / 遥测记录 |
| `[验收]` | 按验收清单逐项确认（转台转速、Z、UVW、屏、触摸、以太网） |
| `[目视]` | 屏上各页逐页看过（与 `[上板]` 不同） |
| `[历史]` | 已被后续版本取代，数字只作血缘证据 |

**生产位流** = 编码器本体，无屏、无以太网，综合时**不带** `ENC_DISP_TAP`。
**显示位流** = 编码器 + 4 页 UI（P1 / P2 / P4 / P6）+ 千兆网，必须带 `-verilog_define ENC_DISP_TAP`
（v74 / v85 / v89 另加 `ENC_V69_CPR2048`；v90 的宏定义以
[`tools/impl_check_disp_v90.tcl`](../tools/impl_check_disp_v90.tcl) 为准）。两者不可混用。

## 2. 关键关系

- **v90 = v74 血缘 + `z_index_gen` + `RTL_BUILD_ID=0x0019`**。改动只有两处：
  `rtl/abz_gen.v` 的 Z 索引发生器（出 Z 后撤防，离开 ≥1/8 圈才重新布防，`Z_ARM_DIST=1<<(AW-3)` = 45°）
  与 `rtl/uvw_gen.v` 回到 v74 的 `e_uw` / `K=4` 参数（此前的改动已回退，**不要再合**）。
  派生脚本 [`tools/make_v90_rtl.py`](../tools/make_v90_rtl.py)，构建脚本
  [`tools/impl_check_v90.tcl`](../tools/impl_check_v90.tcl)（生产）/
  [`tools/impl_check_disp_v90.tcl`](../tools/impl_check_disp_v90.tcl)（显示）。
- **v90 生产位流资源明细**：LUT 10,978（52.78%）、FF 8,724（20.97%）、BRAM 32/50（64%）、
  DSP 17、IOB 60、BUFG 4；WNS **+0.199** / TNS 0 / 0 失败端点（24,691）、WHS +0.017（24,226）。
- **v90 显示位流资源明细**：LUT 17,090（82.16%）、FF 11,601、BRAM 45.5/50（91%）、
  DSP 20、IOB 104、BUFG 5；WNS **+0.221**（33,365 端点）/ WHS +0.049 / WPWS +0.264。
- v90 显示位流删掉 P7 整页与 P1 标定按钮、P2 增加预触发环缓 / 中线 / AUTO 时基；
  同版 BRAM 45.5/50、LUT 82.16%（v85 为 48/50、86.96%）。显示位流资源余量很小，
  再加整页 / 帧缓冲前必须先降分辨率或复用缓冲。
- **v74 是 v90 之前的签核基线**（数据最全、资源余量最大：LUT 52.53%、BRAM 32/50）；
  **v85 与 v89 都是显示位流的中间版本**，只用于追溯 UI 演进。
- **转速只认 Z 频率**：v90 上板 `z_rate` 给出 7.62 / 7.65 Hz ⇒ **457–459 rpm**；
  `check_v70.py` 打印的"机械转速"在高电频段会混叠（621 rpm 是伪值），不得引用。
- 显示位流的 BRAM 从 v71 起就是 48/50，v74 / v85 没有再增加；v90 降到 45.5/50。

## 3. 每个版本怎么复现

| 版本 | 复现命令 / 脚本 |
|---|---|
| v67 | `tools/make_lowsig_rtl.py` → `tools/impl_check_lowsig.tcl` |
| v68 | `tools/make_v68_rtl.py` → `tools/impl_check_v68.tcl` |
| v70 / v71 / v73 | `tools/make_v70_rtl.py` / `make_v71_rtl.py` / `make_v73_rtl.py` → 对应 `tools/impl_check_v70.tcl` / `impl_check_v71.tcl` / `impl_check_v73.tcl` |
| v74 / v85 / v89 | `tools/make_v74_rtl.py` → `tools/impl_check_v74.tcl`（生产）/ `tools/impl_check_disp_v74.tcl`（显示） |
| **v90** | `tools/make_v90_rtl.py` → **`tools/impl_check_v90.tcl`**（生产）/ **`tools/impl_check_disp_v90.tcl`**（显示） |

脚本都在 [`tools/`](../tools/)，每次构建把报告写到 `_impl_*/` 并自动打印
WNS / TNS / DRC / 布线汇总；签核判据见 [`tools/final_verify.ps1`](../tools/final_verify.ps1)。
v90 一条命令签核：`powershell -File tools\final_verify.ps1`。

## 5. 版本选择建议

- **答辩 / 提交**：以 **v90 生产位流**为准（`enc_top_v90.bit`，WNS +0.199、LUT 52.78%、
  BRAM 32/50，转台 457–459 rpm 已复测）。
- **演示屏与上位机**：用 **v90 显示位流**（`enc_top_disp_v90.bit`，已固化 Flash 并通过冷启动），
  话术是"构建签核 + 已下载 + 冷启动通过"。
- **只关心编码器**：v90 生产位流即可，资源余量大（LUT 52.78%、BRAM 32/50）。
- **不要**再把 v74 / v85 / v89 说成"当前基线"——它们只作血缘证据；v89 连归档位流都没有，
  任何数字都不可引用。
