# v68 — 400 mVpp 单端正交 + 显示版（64 周期/转）

> 文档版本：v1.0（2026-10-30）  
> 适用位流：`deliverables/data/v68/enc_top_v68.bit`（生产）、`enc_top_disp_v68.bit`（显示）  
> 构建号：`RTL_BUILD_ID = 0x0010`  
> 口径：`[构建签核]` + `[仿真]`；**未上板**，没有实测数据。

---

## 0. 一句话

把 v67 的 200–300 mVpp 档换成 **400 mVpp 单端、0 V 中心、64 周期/转**：默认数字增益回到
**1.0**（400 mVpp = 0.832 FS，落在默认幅值窗内），ABZ 仍 **4096 A 沿/圈**，并同时交付
**生产位流**与 **“编码器 + 7 寸 LCD + 千兆网”显示位流**。

---

## 1. 为什么必须单独一版

### 1.1 400 mVpp 不能沿用 v67 的默认 1.5

前端仍是方案 B 的 **4.16×**：

```
400 mVpp 单端 × 4.16 = 1.664 Vpp 差分 = 0.832 FS = 3408 码峰峰（峰值 1704 码）
```

- 默认 1.0：0.832 FS，在 `[0.60, 1.20]` 窗内，上电即可 `amp_ok` / `TRACK`。
- 默认 1.5（v67）：0.832 × 1.5 = **1.248 FS**，16 bit 校正输出削顶，`amp_high`/`cor_sat`
  触发，`lock_sm` 会离开 TRACK。所以 v68 必须把 `GAIN_S/GAIN_C` 复位回 **32768**。

### 1.2 单端输入与 0 V 中心

传感器每通道只有一根信号线（对地），不是差分对；AD8138 做单端转差分并放大 4.16×。
输入端必须 **以 0 V 为中心**：任何直流偏置都会被 4.16× 放大，直接吃掉量程甚至饱和。
若传感器带直流偏置，先隔直/交流耦合，或在传感器侧调零，**不要**用数字偏置寄存器硬拉
（`ofs_s/ofs_c` 只能修小量，修不了被放大后的直流）。

### 1.3 幅值窗口

默认 1.0 时：

| 输入 mVpp | 差分 Vpp | ADC 码峰峰 | FS | 默认 1.0 校正后 | 400 mVpp 标定后 |
|---:|---:|---:|---:|---:|---:|
| 288 | 1.198 | 2454 | 0.600 | 0.600（压 `amp_low` 线） | 0.577（amp_low） |
| 300 | 1.248 | 2556 | 0.624 | 0.624 | 0.600（压线） |
| 350 | 1.456 | 2982 | 0.728 | 0.728 | 0.700 |
| **400** | **1.664** | **3408** | **0.832** | **0.832** | **0.800** |
| 450 | 1.872 | 3834 | 0.936 | 0.936 | 0.900 |
| 480 | 1.997 | 4090 | 0.998 | 0.998 | 0.960 |
| 481 | 2.001 | 4098 | 1.0005 | 削顶 | 削顶 |

- **默认 1.0 的可用窗口约 288–481 mVpp**；超过 481 mVpp 前端/ADC 削顶，OTR 会置位。
- **在 400 mVpp 一键标定后** gain≈0.962，可用窗口约 **300–481 mVpp**；300 mVpp 正好压
  `amp_low` 线。传感器幅度随间隙/位置变化时，**在 400 mVpp 附近标定**，不要用 481 mVpp 标定
  （会把 400 mVpp 压到 0.8×400/481≈0.665 FS，余量变差）。

## 2. 硬件前提（方案 B，用户已实施）

| 项 | 值 |
|---|---|
| 前端改造 | R13 4.02 k 短接（建议保留 49.9–100 Ω 串阻）、R15 1 k 不焊 |
| 差分增益 | AD8138 `Rg` 499 → **120 Ω**，`Rf` 499 不动 ⇒ **4.16×** |
| 输入 | 单端、**0 V 中心**、400 mVpp 标称；不削顶最大约 **481 mVpp** |
| ADC | AD9238 双 12 bit，差分 2 Vpp 满量程，偏移二进制（0x800 = 0 V） |
| 1 LSB（SMA 端） | 488 µV / 4.16 ≈ **117 µV** |
| 输出共模 | 每臂围绕 1.65 V（按方案 B 分析），1.03–2.27 V @300 mVpp；400 mVpp 时余量更小，需上板复核 |

> 注意：`docs/27` 的转台/EI58C9 方案是“差分 1 Vpp、G=8”，**不是**本版的单端 400 mVpp；
> 两者不要混用寄存器默认值。

## 3. 与 v66 的 3 处 RTL 差异

由 `tools/make_v68_rtl.py` 把 `rtl/*.v`（25 个）与 `rtl/eth/*.v`（8 个）复制到
`_synth_work_v68/rtl_v68/` 后只改 3 处（`rtl/` 源文件不动）：

| # | 文件 | v66 | v68 | 原因 |
|---|---|---|---|---|
| 1 | `enc_top.v` | `POLE_BITS = 11` | `6` | 64 电周期/圈；机械角 `pos_full[21:6]`；Z 每 64 周期 |
| 2 | `enc_top.v` | `RTL_BUILD_ID = 0x000E` | `0x0010` | 独立构建号（v67 用 0x000F） |
| 3 | `reg_file.v` | `INTER0 = 2` | `32` | 64 周期/转 × 2×32 = **4096 A 沿/圈**（2048 PPR） |

保持 v66 默认：`AMP_LOW_SQ=(0.60)²·2^30`、`AMP_HIGH_SQ=(1.20)²·2^30`、标定 REF=0.8 FS、
`CALIB_N=64`（64 周期/转 = 1 圈）、`ARM_TMO=1 s`、`FILT_K=0x1A`、bias 默认关、UVW pairs=4、
z_width=4。`GAIN_S/GAIN_C` **保持 32768（1.0）**。

## 5. 仿真验证（`[仿真]`）

`sim/tb_v68.v` 对变体 RTL 跑 5 组场景，**37 checks 全过**（14 s）：

| 场景 | 结果 |
|---|---|
| T1 400 mVpp / 默认 1.0 | `GAIN_S/C=32768`、`INTER0=32`、`amp_ok=1`、`amp_low=0`、`amp_high=0`、`cor_sat=0`、`TRACK`、`amp_sq=743,325,696`（0.692·2^30） |
| T2 450 mVpp | `TRACK`、不饱和、`amp_sq=940,771,584`（0.876·2^30） |
| T3 350 mVpp | `TRACK`、`amp_sq=569,108,736`（0.530·2^30） |
| T4 400 mVpp 一键标定 | `calib_done=1`、`res_gain=31,527`（0.962）、shift=0、标定后 `amp_sq=687,269,962`（0.640·2^30）、`TRACK` |
| T5 强拉 1.5 A/B | `amp_sq=1,121,434,660`、`amp_high` 出现过、`cor_sat=1`、非 TRACK；写回 31,527 后 `amp_high=0`、`TRACK` |

关键点：

- T1 同时检查 `r_inter0===32` 与 `cfg_inter===32`，防止只改 `enc_top`、漏改 `reg_file` 的
  `INTER0` 复位值（这是 v68 骨架阶段发现并修掉的缺陷）。
- T4 的标定窗口是 64 个电周期 = 1 机械圈（64 周期/转），标定结果与默认 1.0 无关：
  `0.8 / 0.832 = 0.9615 → 31,527`。
- T5 证明 400 mVpp 不能沿用 v67 的 1.5：1.5 时校正输出削顶，`cor_sat` 置位、锁定丢失。
- 仿真里 24.4 kHz 电频率下仍会打印 `[enc_top] ERROR: 速度为正但延迟修正量为负`，是 `lag_ff`
  3 拍延迟与速度估计在高速下的符号抖动，只影响上报位置、不影响 ABZ/UVW/锁定；目标
  64–128 Hz 手转时 ω 小约 200–380 倍，上板按 §7 复核。
- 本 tb 只做功能验收；角度精度/ABZ 边沿率仍由 `tb_enc_top` / `tb_abz_gen` 覆盖。

## 6. 上板步骤（建议顺序）

> 先按 `docs/28` 做电源/串口/网口，再接传感器。v68 有两个位流：**先验生产版**，再验显示版。
> 关键判据：`0x0000 = 0x0010`、`0x0101 = 32`、`0x0130 = 1`、`0x0514/15 = 0x8000`。

### 6.1 生产位流

1. **下载 `enc_top_v68.bit`，读版本**：`0x0000` 应为 **`0x0010`**；`0x0101` 应为 **32**；
   `0x0514/15` 应为 **0x8000（32768，1.0）**。
2. **UVW 先关或核对**：`0x0100` 复位 4（pairs）；若驱动器不用 UVW，写 `0x0109 = 0x40` 只留 ABZ；
   若用 UVW，把 `0x0100` 改成电机真实极对数（不是 64）。
3. **短路自检**：输入短路时 ADC 码应 **2048 ± 10**；接 400 mVpp、0 V 偏置时约 **3408 码峰峰**
   （峰值 1704）。若中心明显偏离 2048，先查传感器直流偏置/隔直，不要急着标定。
4. **上电锁定**：`0x0130` 应为 **1（TRACK）**；`0x0131` 的 `amp_low/amp_high` 位应为 0；
   `amp_sq` 约 **0.69·2^30**。
5. **一键标定**：先让传感器转起来（≥1 圈），再写 `0x0502`；`ARM_TMO=1 s` 等第一个周期脉冲，
   窗口 64 个电周期 = 1 圈。手转 1 圈/秒时约 2 s 完成。
   - 完成后读 `0x0514/15`：约 **31,527（0.962）**；`0x051A` 的 shift 应为 **0**；
     `amp_sq` 约 **0.64·2^30（0.8 FS）**；`0x0130` 仍为 TRACK。
   - ⚠ 标定把“当前幅值”归一到 0.8 FS。**在 400 mVpp 标定**；若在 481 mVpp 标定，gain≈0.799，
     400 mVpp 会掉到 0.665 FS，余量变差；若在 300 mVpp 标定，400 mVpp 会到 1.067 FS，接近上限。
6. **ABZ**：A 沿 **4096/圈**、Z **1 个/圈**（`inter=32`、64 周期/转、`div=1`）。
   - ⚠ 低速 Z 宽度：`Z_TIMEOUT=4096 clk`，电周期频率低于 **59.6 Hz**（64 周期/转 ⇒ 低于约
     **0.93 转/秒**）时 Z 脉宽被截短；驱动器只取 Z 边沿则无影响。
7. **削顶/OTR**：输入超过约 481 mVpp 会削顶；`0x0405` bit0 写 1 可清 sticky OTR。若 OTR 反复
   置位，先降输入/查直流偏置，不要只清标志。
8. **400 mVpp 仍报 `amp_low`**：先查模拟增益/Rg 焊接和输入直流偏置；确认 400 mVpp 真的到 SMA
   后，可把 `0x0514/15` 临时写到 **1.1–1.15**（36045–37683）再锁定，但 **不要超过 1.2**
   （400 mVpp 会到 0.998 FS，481 mVpp 会削顶）。长期方案是复核前端增益或下调 `AMP_LOW_SQ`。

### 6.2 显示位流

1. 下载 `enc_top_disp_v68.bit`；7 寸屏（1024×600，ATK-7016，DE 模式）应亮，触摸可用。
2. **`key_n` 是全局复位 + 一键标定**（长按复位，释放后按标定流程）；`key1_n` / `ui_btn` 是页切换。
   不要把 `key_n` 当普通页键长按。
3. 屏上 UI 复用 v66 display 的 5 页/触控布局；`ui_inter` 的复位值 **64 只是待写值**，长按会走
   `next_preset`（32→64→…）。**v68 的 ABZ 契约是 `inter=32`（4096 A 沿/圈），不要用屏把
   inter 写成 64**；要改 ABZ 分频请用上位机/寄存器并重新核对边沿率。
4. 网口：显示版包含千兆网，主机可按 `docs/10`/`docs/12` 的 UDP 寄存器协议连；屏与网口是同一
   编码器数据源，不要同时用两套主机写冲突寄存器。
5. 显示版资源 BRAM **48/50（96%）**，不要再加帧缓冲/新页；改 UI 前先看 `disp_util.rpt`。

## 7. 风险与限制（如实登记）

| # | 风险 | 影响 | 处置 |
|---|---|---|---|
| 1 | **未上板** | 只有构建 + 仿真，无实测 | 按 §6 先生产后显示；记录 ADC 码/锁定/标定 |
| 2 | 生产 WNS 仅 **+0.144** | 比 v67 +0.282 低，温度/电压角余量变小 | 上板做 10 分钟烤机 + 反复复位；若异常，用 v67 的 Explore 重跑或降频 |
| 3 | 显示 BRAM **48/50（96%）** | 再加缓冲/页会放不下 | 任何显示逻辑改动先看 `disp_util`；不要加帧缓存 |
| 4 | 400 mVpp 是**标称点** | 288 mVpp 以下 `amp_low`，481 mVpp 以上削顶 | 传感器幅度变化时在 400 mVpp 附近标定；不要用 481 标定 |
| 5 | 单端/直流耦合 | 传感器直流偏置被 4.16× 放大，吃量程/饱和 | 输入端必须 0 V 中心；有偏置先隔直/调零 |
| 6 | 481 mVpp 上限 | 过冲/上电冲击触发 OTR/削顶 | 加 49.9–100 Ω 串阻/BAV99 钳位；`0x0405` 清 OTR |
| 7 | Z 宽度低速截短 | <0.93 转/秒时 Z 脉宽变短 | 驱动器只取边沿；要保宽度需改大 `Z_TIMEOUT` |
| 8 | `lag_ff` 高速仿真告警 | 24.4 kHz 仿真下上报位置符号抖动 | 目标 64–128 Hz 手转；上板低速复核上报角度 |
| 9 | 显示 UI 的 `inter` 预置 64 | 误写会把 ABZ 变 8192 A 沿/圈 | 不要用屏改 inter；用寄存器并复核 |
| 10 | 显示构建必须带 `ENC_DISP_TAP`（以及 `ENC_V68_CPR64`） | 漏 `ENC_DISP_TAP` 会因 `disp_tap` 端口缺失而综合失败；漏 `ENC_V68_CPR64` 屏上 RPM/转数会按 `pairs=4` 显示为 16× | 只用 `tools/impl_check_disp_v68.tcl`；生产不要带任何 display define |
| 11 | Vivado 收尾不退出 | 作业显示 running，易误判 | 以位流时间戳/哈希/报告为准；落盘后外部终止 |
| 12 | 屏上 RPM/转数依赖 `ENC_V68_CPR64` | 手工综合漏这个 define 时，`val_format` 仍按 5bit `pairs`（默认 4）换算，64 周期/转会显示为实际转速的 **16×** | 本仓库的 `tools/impl_check_disp_v68.tcl` 已带；角度/ABZ/UVW 不受影响，精确转速用上位机/角度差分 |

```powershell
    -LogFile _impl_v68/vivado.log -Tail 40

    -LogFile _impl_disp_v68/vivado.log -Tail 40
```

> 构建两条位流时**不要并发**：Vivado 在同一工作目录会争 `.Xil`/临时文件，实测会报
> `ERROR: [Common 17-1257] Failed to create directory 'C'.` 并以 exit 1 结束。
> 顺序跑，且每次先清 `vivado_pid*.str`。
