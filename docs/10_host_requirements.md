## 0. 一句话目标

做一个 **Windows 上双击就能用的图形化软件**（简约、直观、淡蓝色主题），
用一根 USB 线连到 FPGA 板，实现：找端口 → 连上 → 看波形和数据 → 调倍频倍率 → 存记录。

## 1. 确认结论（v1.0 定稿决策）

| # | 议题 | 用户决定 | 对本工程的含义 |
|---|---|---|---|
| 1 | 交付形式 | **源码 + 最终打包 exe（两个都要）** | 开发期用源码快速迭代；功能稳定后出单文件 `.exe`，双击即用、目标机不需装 Python |
| 2 | 使用者定位 | **自己调试用，但按"可给老师/评委演示"的标准做** | 界面要干净、数值要大要清楚；提供一键演示式的简洁流程 |
| 3 | ABZ/UVW 波形 | **等效采样波形 + 六状态数据表** | 按电角度分箱拼接波形；UVW 六状态驻留统计表；不试图用时间轴画高速 A/B |
| 4 | 转速显示 | **机械转速 RPM + 电频率 Hz + 方向 + 累计圈数** | 极对数做成可填参数（默认 4），RPM 由它换算 |
| 5 | v1 范围 | **先把核心做扎实：端口 + 倍频 + 转速 + 波形** | v1 = M1~M6，外加 M7 基本告警显示；**一键标定（M8）放 v2** |
| 6 | 配色 | **按建议方案**：底 `#EAF3FB`、卡片白、强调 `#2E7DD1` | 具体色板见 §2 |
| 7 | 数据记录 | **需要**：一键记录存 CSV + 导出波形 PNG | 记录内容见 M6 |

**环境事实（已实测）**：本机已插着目标板 —— `COM3 — USB-SERIAL CH340`，
`USB VID:PID=1A86:7523`。⇒ 开发过程中可以**对着真机验证**，不必等到最后。

**极对数默认值**：`0x0100 UVW_CFG` 复位默认 = `0x04`（4 对极），
软件默认取 4，用户可改；界面上显示"当前使用极对数 = N"。

## 2. 界面设计（简约、直观、淡蓝主题）

- **布局**（单窗口，三段式）：
  - 顶部连接条：串口下拉框 / 刷新 / 连接 / 断开 / 状态灯；
  - 中部波形区：标签页 —— ①"输入波形" ②"ABZ / UVW" ③"速度与位置"；
  - 底部：大字号数值卡片 + 状态栏（帧率 / 丢帧 / 校验错 / 已运行时长）。
- **配色（定稿）**：
  | 用途 | 色值 |
  |---|---|
  | 页面背景 | `#EAF3FB` |
  | 卡片背景 | `#FFFFFF` |
  | 主强调（按钮/曲线1/选中） | `#2E7DD1` |
  | 次级（曲线2/次要描边） | `#8FC4EC` |
  | 正文 | `#1F2D3D` |
  | 正常 | `#3FA45B` |
  | 警示 | `#E08B2D` |
  | 故障 | `#D9453D` |
- **交互原则**：全中文；按钮直白（"连接"/"断开"/"开始记录"/"停止"）；

  关键参数旁有简短说明。

## 3. 功能模块

### M1 通信端口：自动 / 手动检索 【v1】
- 自动：启动即扫描串口，列表显示成 `COM3 — USB-SERIAL CH340`（带设备名）。
- 手动：下拉框选择 + "刷新" + 允许手工输入端口号。
- 通信参数：`2,000,000 / 8 / N / 1`，放在"高级设置"里，默认不动。
- 连接后自检：读 `0x05F0 DEVICE_ID`（应 `0x0C`）、`0x05F1 REV`（应 `0x10`）、
  `0x05F2` 固件版本（当前 v12 = `0x000C`）；不符则明确提示型号/版本不匹配。
- 拔线/断电 → 提示"连接已断开"并可一键重连；不崩、不卡死。

### M2 倍频（插补）倍率与输出参数 【v1】
- 主参数：
  - `inter` 插补倍数（每输入周期的 AB 周期数）`2…256`（写 0 视为 256）；
  - `div` 后分频 `1…8`；
  - 实时换算显示：等效倍率 `inter/div`；AB 边沿率 ≈ `4 × inter / div × f_in`（Hz）。
- 写入流程：点"应用" → 写 `0x0101` / `0x0102` → **自动回读比对** → 显示"已生效/未生效"，
  失败给重试按钮。
- 常用倍率一键预设（如 64 / 256）。
- 高级折叠区（都要中文名 + 取值范围 + 当前有效值）：
  AB 迟滞 `hyst`(0x0103)、AB 限频 `ablimit`(0x0106)、Z 相位 `zphase`(0x010A)、
  Z 宽度 `zwidth`(0x0108)、ABZ 极性/方向与 ABZ/UVW 使能(0x0109)、
  UVW 极对数 `pairs`(0x0100)、UVW 相位(0x010B / 0x010C)。

### M3 转速与位置 【v1】
- 数据来源：遥测帧 `angle`（每周期 65536）与 `pos_full`（含多周期计数）。
- 计算：电频率 `f_in`(Hz)；机械转速 `RPM = f_in × 60 / 极对数`；方向；累计圈数/多周期计数。
- 平滑（时间窗可调）避免数字乱跳；界面显示所用极对数。
- 标注"估算值，用于观察不用于计量"（受 10 kHz 帧率与 USB 抖动限制）。

### M4 输入信号波形 【v1】
- `s_n` / `c_n` 实时时域波形（校正后 Q1.15）。
- 李萨如圆（`s_n` vs `c_n`）：一眼看幅值、正交/偏置误差、噪声、过载。
- 数值面板：幅值（LSB 与伏特两种换算）、幅值告警、`OTR` 过载标志。

### M5 ABZ / UVW 波形与数据 【v1】
- 能做：六路电平滚动显示（A/B/Z/U/V/W，遥测帧直接携带）；`dir`、`limiter_active`、
  `z_window` 与告警位；**等效采样波形**（按电角度分 64 或 128 箱拼接）；
  UVW 六状态驻留统计（是否出现非法 `000`/`111`、相序方向）；
  Z 脉冲重复率与宽度（按参数换算）；边沿计数 / 占空比数据表。
- **做不到并如实标注**：A/B 边沿率最高 2.559 MHz，而遥测仅 10 kHz ⇒
  按时间轴画必然混叠；边沿级波形要靠等效采样或示波器/ILA（界面给提示文字）。

### M6 数据记录与导出 【v1】
- "开始记录 / 停止记录"；存 CSV（原始 18 字节帧 + 解析列 + 上位机时间戳）；
- 一键导出当前波形为 PNG；
- 显示本次记录时长、帧数、校验错帧数、丢帧估计。

### M7 状态与告警 【v1：基本显示】
- 中文 + 颜色显示：`OTR`、`amp_low/amp_high`、`cor_sat`、`limiter_active`、
  `lag_warn` / `lag_fatal`、`caldone` / `calbusy`；
- "清锁存故障"按钮（写 `0x0405`，W1C，注意与 TW28 写 0 清位语义相反）。

### M8 一键标定 【v2，不在本次范围】
- 一键标定：设窗口 `0x0503/04` → 触发 `0x0502` → 轮询 busy/done → 显示六个校正参数与角度误差对比；

## 4. 关键技术约束（决定"什么能做什么不能做"）

1. **只有一条链路**：板载 CH340E 串口，`2 Mbaud 8N1`；遥测与寄存器读写共用该口
   （下位机内部仲裁），上位机必须"发一条 → 收到应答 → 再发下一条"。
2. **遥测帧**：18 字节定长、大端，帧头 `AA 55`，末字节 XOR 校验（**含帧头常量**），
   10 kHz 帧率，**链路占用 90.7%（余量仅 9.3%）** ⇒ 上位机必须持续稳定读。
3. **帧布局 v2**（现行）：`angle` / `s_n` / `c_n` / `io_state`(A B Z U V W + dir + limiter)
   / `0xA2` 布局标记 / `io_flags` / `pos_full` / `stat` / 校验；
   需按"布局标记字节"自动识别 v1/v2 并提示。
4. **时间分辨率 = 10 kHz（0.1 ms）**，是软件的时间轴极限。
5. **下位机不给转速**，只给角度与位置，转速由上位机算。
6. **寄存器读写**：4 字节命令 → 6 字节应答（`0x5A … chk`）；读命令连发两帧，写命令只发一帧。
7. **可复用资产（不重写协议）**：
   - `tools/uart_scope.py`：遥测帧解析/组帧/可视化（含 `--selftest`）；
   - `tools/uart_spi.py`：4 字节命令读写任意寄存器（含 `--selftest`、离线 `--file`）；
   - `tools/demo_abz_uvw.py`：ABZ/UVW 电平观测 + 版本门禁 + 等效采样 + 归档。
8. **本机环境已就绪**：Python 3.13.9；`PySide6 6.9.2`、`PyQt5 5.15.11`、
   `matplotlib 3.10.6`、`numpy 2.3.5`、`pandas 2.3.3`、`pyserial 3.5`（`pyqtgraph` 未装）。

## 5. 技术选型（定稿）

| 项 | 选择 | 理由 |
|---|---|---|
| 语言/框架 | Python 3.13 + **PySide6** | 本机已装；界面美观、中文友好、控件齐全 |
| 波形绘制 | **matplotlib 嵌入 Qt**（如后续刷新率不足再评估 pyqtgraph） | 已装，零额外依赖 |
| 串口 | `pyserial` + **独立读线程 + 队列** | 2 Mbaud / 10 kHz 必须异步读，界面不阻塞 |
| 打包 | **PyInstaller 单文件 exe** | 双击即用，目标机不装 Python |
| 代码位置 | 新建 `host/` 目录；**不改动现有 `tools/` 脚本** | 现有工具被文档与测试引用，保持可用 |

## 6. 暂不做（v1 范围外）

- 网口 / CAN / EtherCAT 等其它通信方式；
- 实时 FFT、阶次分析等高级信号处理；
- 固件在线升级（软件烧 `.bit`）；
- 同时连多块板；移动端 / 网页版；
- 一键标定面板（M8，v2）。

---

## 7. 验收标准（v1 判据）

1. 打开软件，插好 USB 后 **30 秒内**连接成功并显示实时数据；
2. 端口列表正确列出 CH340；拔掉设备刷新能反映变化；
3. `inter` 从 64 改到 256 后界面显示的 AB 边沿率随之变化，且**回读确认生效**；
4. 转速与已知输入频率一致（信号发生器给已知频率，误差可解释）；
5. 输入波形与李萨如圆连续刷新不卡顿（界面刷新 ≥ 10 次/秒）；
6. ABZ/UVW 等效采样波形正确显示 A/B 90° 正交关系与 UVW 六状态均衡；
7. 连续运行 30 分钟不崩、不卡死，记录文件可正常打开；
8. 拔掉 USB 再插回，软件能恢复显示（不要求自动重连，但必须不崩溃）。
