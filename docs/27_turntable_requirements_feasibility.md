## 0. 一句话结论

**可行，而且路径比想象中短**：现有 v62 已经具备"12 bit 同步采样 → 六参数校正 → 16 bit 流水 CORDIC → PI 环路 → ABZ/UVW"的全链路，50 kHz 电气频率相对已验证的 700 kHz 带宽有 **14 倍余量**，算角度本身不是难点。

**真正的难点只有三个**，都不在"算角度"上：

1. **变频段的滤波一致性**——转速从 0 到最高，滤波器带宽若固定，相位滞后（以电角度计）会随转速剧烈变化，标定补偿全部失效；
2. **偏置/增益的长期漂移**——一次性标定在温升 20 ℃ 后会退化，尤其前端是"单端 0.5 Vpp → 放大 16 倍"这种小信号高增益结构；
3. **异常状态下的可控性**——上电静止、信号丢失、削顶、反转抖动、失锁，必须有明确状态机与输出策略，否则多圈计数会跑飞。

外加一个**反直觉但很关键**的结论（见 §4.5）：当 PPR=2048 时，机械 1″ 只对应电角度 0.57°，**FPGA 细分精度根本不是瓶颈**，传感器刻度误差与安装偏心才是。所以"做到完美"的投入应该压在**标定 + 鲁棒性**，而不是再加 CORDIC 位宽。

### ⚠️ 0.5.1 一处必须澄清的不自洽

2048 PPR 时：`f_el(Hz) = rpm × 2048 / 60`

| 转速 | 电气频率 | vs "50 kHz" |
|---|---|---|
| 1000 rpm | 34.1 kHz | — |
| **1465.9 rpm** | **50.0 kHz** | 你给出的上限对应的转速 |
| 3000 rpm | **102.4 kHz** | **超出 2 倍** |

## 3. 信号链预算（把"能不能"算清楚）

### 3.1 电平与码值

| 项 | 数值 | 说明 |
|---|---|---|
| ADC 满量程 | ±5 V 单端（10 Vpp） | 模块分压 ÷5 后进 AD8065 |
| 输入 8 Vpp | ±4 V | 占满量程 **80%** |
| 峰值码值 | 4 V / 2.44 mV = **1638 码** | 理论 ±2048 |
| 码值动态范围 | 20·log10(1638/0.289) ≈ **72 dB** | 等效 ~11.7 bit |
| 削顶余量 | 10/8 = **1.25×（+1.9 dB）** | 幅值涨 25% 就削顶 |
| 建议 | 7.0–8.0 Vpp，且必须实测 DC 偏置 | 见风险 R1 |

### 3.2 频率与采样

| 电气频率 | 每周期采样点（50 MSPS） | 抽取 4 后 | 每点电角度 |
|---|---|---|---|
| 1 kHz | 50,000 | 12,500 | 0.0072° |
| 10 kHz | 5,000 | 1,250 | 0.072° |
| 50 kHz | **1,000** | **250** | **0.36°** |

50 kHz 时仍有 250 点/周期，**采样不是瓶颈**。瓶颈在 ABZ 边沿率：`4×inter×f_in ≤ 12.5 MHz` ⇒ 50 kHz 时 `inter ≤ 32`；若走寄存器/遥测读 16 bit 角度，则不受此限。

### 3.3 电气角度 → 机械角度（**全篇最重要的换算**）

$$\varepsilon_{mech}(″) = \frac{\varepsilon_{el}(°) \times 3600}{PPR}$$

| PPR | 1″ 机械对应的电角度 | 0.1° 电角度对应的机械误差 |
|---|---|---|
| 1024 | 1.14° | 0.35″ |
| 2048 | **0.57°** | **0.18″** |
| 4096 | 0.28° | 0.09″ |
| 2500 | 0.47° | 0.14″ |

**含义**：PPR 越高，对"电角度精度"的要求越松。2048 时，电角度做到 0.5° 就够 1″ 机械精度——而当前 CORDIC 是 0.005° 级，**过剩 100 倍**。

### 3.4 延迟预算（50 kHz 时 1 µs = 18° 电角度）

| 环节 | 延迟 |
|---|---|
| ADC 采样 + 捕获 | 1–2 拍（40 ns） |
| 抽取（N=4…64） | 2…64 拍（40 ns…1.28 µs） |
| 校正 | 3 拍（60 ns） |
| CORDIC | 17 拍（340 ns） |
| 环路 + 输出 | ~5 拍（100 ns） |
| **合计** | **≈0.6–1.8 µs** |

对 100 Hz 伺服带宽，1.8 µs 相移 0.065°，可忽略；对位置精度，可用测速值做 `ω·τ` 前馈补偿。

## 4. 可行性分析

### 4.1 总判断

| 维度 | 判断 | 依据 |
|---|---|---|
| 采样与算力 | ✅ **富余** | 50 kHz vs 700 kHz 已验证带宽；CORDIC 吞吐 1 点/拍 |
| 电平接口 | ⚠️ **可行但余量小** | 8 Vpp/10 Vpp = 80%，削顶余量仅 25% |
| 细分精度 | ✅ **过剩** | 见 §3.3，机械精度不由细分决定 |
| 变频适应 | ⚠️ **需新增** | 现有抽取固定，环路增益固定 |
| 长期精度 | ⚠️ **需新增** | 一次性标定无法跟踪温漂 |
| 异常处理 | ⚠️ **需新增** | 缺统一状态机 |
| 资源 | ⚠️ **紧** | BRAM 46/50，LUT 82% |
| 工期 | ⚠️ **紧** | 若赶 11-04，只能做最小闭环 |

**结论：技术路线成立，风险集中在"模拟前端余量"与"自适应/诊断逻辑的新增工作量"，不在算法本身。**

### 4.2 六个关键难点与对策

#### A. 变频段的滤波一致性（最难，也最容易被忽略）

**机理**：固定带宽 LPF 的群延迟 τ 是常数（秒）。角度误差 = ω·τ，随转速线性增大；同时噪声抑制随频率变化。结果是"低速很干净但高速滞后 18°，或高速跟得上但低速噪声大"。

**对策（三层，按代价从低到高）**：

1. **归一化抽取**：让每周期采样点数近似恒定，`N = clamp(round(fs/(K·f_est)), 4, 64)`，K≈64–128。箱形平均对 sin/cos 同相，不引入正交误差，只引入与 N 成正比的群延迟（可测、可补偿）。代价：N 切换瞬间有相位台阶，需在过零/匀速段切换或做交叉淡化。
2. **环路增益调度**：`kp/ki` 随 |速度| 分段切换（低速重滤、高速轻滤），保持"电角度滞后"恒定。现成寄存器就能做，代价最小。
3. **速度前馈补偿**：用测速值把 `ω·τ` 从输出角度里减掉，等价于零延迟。需要准确 τ（可标定）。

> 推荐组合：**1（粗调，4/8/16 三档）+ 2（细调）+ 3（补偿）**，不要一上来做分数延迟重采样。

#### B. 偏置/增益漂移

**机理**：0.5 Vpp/腿 的小信号被放大 16 倍，前端偏置漂移被同倍放大。偏置 d（相对幅度）造成的角度误差 ≈ d rad。d=1% ⇒ 0.57° 电角度 ⇒ 2048 PPR 时 1.0″ 机械。温升 20 ℃ 漂 10 mV（相对 0.25 V 幅度 = 4%）⇒ 4″，**足以吃掉全部精度预算**。

**对策**：
- 上电/停机时自动重标定（现有 calib_ctrl 已支持一键标定，扩展为"条件触发"）；
- 运行中**只跟踪偏置**（2 参数 LMS，时间常数 5–30 s），增益/正交保持标定值；
- 加速段、过零段冻结自适应，避免把"真实运动"学成"偏置"；
- 用 `amp_monitor` + OTR 做"标定有效性"看门狗：幅值/偏置超窗 ⇒ 标定失效标志。

#### C. 正交/增益/谐波误差

- 正交与增益失配：六参数已覆盖（2 次谐波），残差 <0.1″（2048 PPR）。
- **3/5/7 次谐波**：来自传感器磁场谐波与探测器非线性，六参数**无法**消除，表现为 4/6/8 次/转的周期性误差，典型 0.1–1° 电角度 ⇒ 0.2–2″ 机械。
- 对策：**角度域误差补偿表**（LUT）。1024 点 × 16 bit 只需 ~16 Kb，可放分布式 RAM（约 256 LUT），不必抢 BRAM；标定需要一个外部基准（见 R6）。

#### D. 低速测速

**机理**：16 bit 角度在 2048 PPR 下，1 LSB = 0.0097″ 机械。10 kHz 更新时，1 LSB/帧 = 0.097″/10 ms = **9.7″/s**——低速时速度量化粗到不可用。

**对策**：M/T 法（测周期 + 测脉冲数）+ 长窗口 + 与环路速度融合；明确"最低平稳转速"指标（PR-03），低于该转速只保证位置不保证速度纹波。

#### E. 启动 / 失锁 / 故障

必须新增**统一状态机**：

```
POR → 自检 → 搜索（等幅值有效） → 捕获（等相位锁定） → 跟踪
                                   ↑                    │
                                   └── 失锁 ←───────────┘
                                          ↓
                                    故障（幅值/削顶/超速/正交异常）
```

要点：
- 静止时 sin/cos 是直流，atan2 仍有输出但无意义 ⇒ **必须用幅值门限判定"信号有效"**，无效时输出保持 + 有效位=0；
- 多圈计数只在"跟踪"态累加，故障态冻结；
- 反转过零附近加迟滞，避免抖动计数（abz_gen 已有滞后逻辑，需推广到 pole_counter）。

#### F. PWM 干扰与模拟前端

- 模块**没有抗混叠滤波器**，电机 PWM（8–20 kHz）及其谐波直接进 ADC；
- 对策：前端加二阶 RC/有源 LPF（截止 200–300 kHz，不影响 50 kHz 基波）、双绞屏蔽、单点接地；数字侧可在 PWM 频率做陷波，但 PWM 频率若可变则不牢靠——**优先在模拟侧解决**；
- 若驱动器能给出 PWM 同步信号，可用"PWM 中心对齐采样"把开关噪声搬到采样零点，这是最彻底的办法（需硬件引入同步信号）。

### 4.5 精度可行性（误差预算，PPR=2048）

| 误差源 | 电角度 | 机械角（″） | 能否靠 FPGA 消除 |
|---|---|---|---|
| ADC 量化（8 Vpp，4 倍平均） | 0.005° | **0.009** | — |
| 偏置残差 0.1% | 0.057° | **0.10** | ✅ 标定 |
| 增益失配 1% | 0.29° | **0.50** | ✅ 标定 |
| 正交误差 0.1° | 0.05° | **0.09** | ✅ 标定 |
| 3 次谐波 0.1% | 0.06° | **0.10** | ✅ LUT |
| CORDIC | 0.005° | 0.009 | — |
| **传感器刻度误差** | — | **±10…±40** | ❌ 需外部基准标定 |
| **安装偏心 10 µm @ R50** | — | **≈41** | ❌ 机械/软件偏心补偿 |

**结论（针对已确认的 ±1″）**：

1. **FPGA 内部算法误差合计 <0.3″**（量化 0.02 + 校正残差 0.2 + 谐波残差 0.1，方和根 <0.25″），对 ±1″ 目标有 **4 倍以上余量**——细分、CORDIC、六参数校正**都已经过剩**，不要再加位宽。
2. **瓶颈是传感器本体**：刻线误差 ±10…40″ + 安装偏心（10 µm @ R50 ≈ 41″），合计可达 **50″**，是目标的 50 倍。
3. 但这两个误差都是**角度上的确定性函数**（同一位置每次都一样），因此可以被 **全周 LUT 吸收**。吸收后的残差 = 误差的**重复性**（插值噪声、温漂，典型 **1–3″**）+ **标定基准自身的精度**。
4. 所以 ±1″ 的可行性等价于三个条件：
   - 有 **±0.5″ 级基准**（高精度转台 / 自准直仪 + 多面棱体 / 多读数头平均）；
   - **偏心稳定**（同轴度、温升后不漂）；
   - 补偿表覆盖**全周 2^N 点**（2048 周期 × 每周期 ≥16 点 ⇒ 建议 32768 点，或用"每周期 16 点 + 周期序号偏移"的简化结构）。

> **直白地说**：代码侧做到 ±1″ 是**可实现的**，但如果拿不到好基准、或传感器偏心随温漂变化，实际只能到 **±3…5″**。这不是算法问题，是测量学问题。**建议同时准备一个 ±5″ 的可交付版本**，把 ±1″ 作为"有基准时的增强模式"。

## 9. 附录：关键公式

**六参数校正**（对应 `rtl/sc_correct.v`）：

```
s1 = s − O_s
c1 = c − O_c
c2 = c1 − (s1·k_φ) >> 15          // 正交校正
s2 = (s1·K_s) >> (15 − sh_s)      // 增益均衡
c3 = (c2·K_c) >> (15 − sh_c)
θ  = atan2(s2, c3)
```

**误差灵敏度**（小误差线性化，ε 为相对幅度）：

| 误差 | 角度误差（rad） |
|---|---|
| 偏置 d | ≈ d |
| 增益失配 ε | ≈ ε/2 |
| 正交 φ | ≈ φ/2 |
| n 次谐波 h_n | ≈ h_n（在 nθ 频率上） |

**机械/电气换算**：`ε_mech(″) = ε_el(°)·3600/PPR`

**ABZ 限频**：`4·inter·f_in ≤ 12.5 MHz`

**环路**：`ω_n = √Ki·fs`，`ζ = (Kp+Ki)/(2√Ki)`，`f₋₃dB ≈ 2.2 MHz`（kp=0/ki=3）

## 12. v1.1 扩展：高转速兼容 与 高精度阶梯（2026-10-27 补充确认）

你补充了两条：**① 最高转速要留更大余量、广泛兼容；② 精度越高越好，要体现技术水平。** 本节把这两条落成可执行的指标。

### 12.1 速度天花板在哪：200 kHz 是这套硬件的物理上限

传感器 EI58 的响应频率是 **200 kHz**，机械极限 **5000 rpm**；两者在 2048 PPR 下正好对应：

| 转速 | 电气频率 | 备注 |
|---|---|---|
| 1465.9 rpm | 50 kHz | 你最初给的上限 |
| 3000 rpm | 102.4 kHz | |
| 5000 rpm | **170.7 kHz** | EI58 机械极限 |
| 5859 rpm | **200 kHz** | EI58 响应极限 |

**决策：程序按 200 kHz 电气频率设计**（= 5859 rpm）。理由：
- 覆盖 EI58 全部可用转速（5000 rpm）并留 **17% 余量**；
- 50 MSPS 下 200 kHz 仍有 **250 点/周期**，完全够；
- 前端 700 kHz 带宽还有 3.5 倍余量，**不改任何硬件**；
- 超过 200 kHz 时瓶颈变成传感器本身（幅值衰减、相位滞后），FPGA 再快也没用——所以这是"广泛兼容"的**合理边界**，不是偷懒。

### 12.3 抽取档位：让"电角度滞后"恒定，而不是让带宽恒定

箱形平均的群延迟 τ = N/(2·fs)，电角度滞后 = 360°·f·τ。若 N 固定，滞后随转速线性增长（低速 0.3°、高速 18°），标定补偿全部失效。

**设计规则：N 随 f 反比变化，使滞后恒定在 0.3–0.7° 电角度**：

| 电气频率 | N | 电角度滞后 |
|---|---|---|
| ≤1.5 kHz | 64 | 0.35° |
| 1.5–3 kHz | 32 | 0.35°–0.69° |
| 3–6 kHz | 16 | 0.35°–0.69° |
| 6–12 kHz | 8 | 0.35°–0.69° |
| 12–25 kHz | 4 | 0.35°–0.72° |
| 25–50 kHz | 2 | 0.36°–0.72° |
| >50 kHz | 1 | 0.36°–1.44° |

再叠加 **ω·τ 前馈补偿**后，残差 <0.1″ 机械。**这是"变频适应"的核心，也是它区别于普通编码器接口的地方。**

## 14. UVW 默认关闭的原因与 Z 信号接入方案（2026-10-28）

### 14.1 UVW 为什么复位默认是关（`reg_file.v:298 r_output <= 8'h40`，bit7=uwven=0）

不是"保守"，是**这套拓扑下 UVW 的语义还没接对**：

`rtl/uvw_gen.v` 的输入 `angle` 是**一个正弦周期内的角度**，内部 `eang = (angle·pairs + uvwph·2^(AW-10)) mod 2^AW`。
对 2048 周期/转的 EI58，一个正弦周期 = 1/2048 转，所以：

```
电周期/转 = 2048 × pairs        （pairs=4 → 8192 电周期/转）
```

而真实电机需要的是 **P 个电周期/转**（P = 极对数）。两者差 2048 倍。所以现在打开 UVW，输出的是**频率错 2048×、相位与转子磁极无关**的三相方波——波形"看着像"，但驱动器拿它做换向初始化会直接换错向。

第二个原因：上电后到 `filt_valid` 有效之前，`angle` 无意义（无信号时 atan2 输出任意值）。`uvw_gen` 只在 `in_valid` 时更新输出（`uvw_gen.v:539`），复位值 0，所以这段时间输出是 000——这点是安全的，但一旦锁定就会立刻按错误公式输出。

**结论**：不能"把 bit7 置 1"了事。正确开启要按 `docs/20` §7.5 改：把**机械角** `mech = {cycle_cnt[POLE_BITS-1:0], angle[AW-1:AW-5]}`（16 bit，整转）送进 `uvw_gen`，`pairs` 填**真实极对数 P**，此时 `电周期/转 = P`，UVW 才成立。

**风险分级**：
- 驱动器**不用** UVW（走 ABZ 闭环）：只是 3 根 8 mA 的快沿信号在电缆上跑，属 EMI 噪声源，功能无害；
- 驱动器**用** UVW 做上电换向：相位错 ⇒ 换向错 ⇒ 转矩方向错/堵转/过流，**这是真实风险**。

### 14.2 Z 信号不能直接接 FPGA

EI58 的 Z 是 **RS422 差分**（Z+/Z−，5 V 供电，共模 2.5 V），FPGA 的 LVCMOS33 引脚既不能收差分、也受不了 5 V。必须经过接收器：

```
编码器 Z+ ──┬── 120Ω ──┬── AM26LS32 / AM26LV32 (3.3V 供电) ── 33Ω 串阻 ── FPGA GPIO (LVCMOS33)
            │          │                                              │
编码器 Z− ──┴──────────┘                                     (建议再串 Schmitt 或 74LVC1G17)
```

| 注意点 | 具体要求 |
|---|---|
| 电平 | 接收器输出必须是 **3.3 V CMOS**；若用 5 V 的 26LS32，后面必须加电平转换，**不能 5 V 直怼引脚** |
| 终端 | 双绞线较长（>0.5 m）时在接收端跨接 **120 Ω**；短距离可省，但共模噪声会变大 |
| 共模范围 | AM26LS32 允许 −7…+12 V，够用；若编码器与 FPGA 地电位差大，改用隔离型（Si8641/ADuM1201） |
| 走线 | Z 与 A/B 同缆、屏蔽层单端接地；不要与 PWM 动力线并行 |
| 引脚 | 需一根 **J5 空闲针**（J6 已被 AD9238 模块占满，见 `constr/enc_top.xdc:274`），且必须在 XDC 里显式绑定，**不能凭猜** |
| 消抖 | Z 每转只来一次，一次误触发就是丢掉一圈。RTL 必须做 2 级同步 + 边沿检测 + 窗口校验（只在 `cycle_cnt` 低 `POLE_BITS` 位接近 0 时接受），不匹配累计 N 次报 `z_err` |

**RTL 需要新增**（S3 一起做）：`z_in` 端口 → 2 级同步 → 双边沿检测 → 与预测窗口比对 → 命中则锁存 `cycle_cnt`/`angle` 偏移（或直接清零周期计数器）→ 连续失配计数 → `z_err` 标志。顺带可做 PPR 自动识别与方向自动判别。

### 14.3 一个容易忽略的事实：现在的"虚拟 Z"其实已经是 1 转 1 个

`enc_top.v:701 z_window = (cycle_cnt[POLE_BITS-1:0] == 0)`，`POLE_BITS=11` 后 cycle_cnt 每 2048 个正弦周期（= 1 转）清零一次 ⇒ **虚拟 Z 已经严格 1 脉冲/转**，只是零点锁在"某个正弦周期的过零点"，不是编码器的机械索引。

所以真实 Z 的作用只剩三件：**① 把零点对齐到机械索引；② PPR 自动识别；③ 方向自动判别**。如果转台每次上电都回零（homing），这三件都不是必须的；如果要"上电即知绝对位置"，就必须接。

*需求基线 v1.2：PPR=2048（EI58）、每腿 0.5 Vpp、8 Vpp 零偏置、**200 kHz/5859 rpm**、**±1″（C 档）**、闭环+记录双用。**S1 已完成（RTL 已改）**，下一步 S2。*

### 15.2 上位机：8 个确定缺陷（B1–B8）

- **B1/B2（高危，会静默改坏配置）**：UART→SPI 桥一次事务写 **2 字节**（低字节→addr，高字节→addr+1）。原来写 `0x0100` 极对数时高字节 0 落到 `0x0101`（倍频被清零），写 `0x0102` 时高字节 0 落到 `0x0103`（AB 迟滞被清 0）。⇒ 改为**一次 16 位写**（倍频/分频合并）与**读-改-写**（极对数保留高字节）。
- **B3/B4（假死）**：串口写超时只报错不断开、且没有"多久没数据"的判据 ⇒ 板子掉线界面还是绿的。⇒ 加链路看门狗（3 s 警告 / 15 s 自动重连，最多 3 次），打开失败也补发 `closed` 事件。
- **B5（卡 UI）**：开流时在 GUI 线程同步写寄存器，最坏 5 s。⇒ 先绑 socket（被占则用系统分配端口），寄存器写入挪进后台任务并回读核对。
- **B7**：UDP 收包线程只捕 `OSError`，其他异常静默死亡。⇒ 兜底 `Exception`，单包解析失败不杀流（记 `bad_packets`）。
- **B8**：只装 `sys.excepthook`，打包 exe 里线程崩溃无记录。⇒ 补 `threading.excepthook`。

### 15.3 UVW：真正的原因不是"保守"，是**错拍**

上一版把机械角写成 `{cycle_cnt, angle}` 现拼，`cycle_cnt` 是寄存器、`angle` 是当拍组合值，**正弦周期回绕那一拍两者差一拍** ⇒ 机械角瞬退 `65536/2048` 格，UVW 出现 1 clk 宽的假扇区跳变。tb 抓到：`min_dwell=1 clk`、`sector_transitions=38`（应为 24）、`warn_hi=1786120`。

修法：改切 `pole_counter` 的原子输出 `pos_full[POLE_BITS+AW-1 : POLE_BITS]`（`pos_full` 与 `cycle_cnt` 同一拍更新）。修复后：`sector_transitions=24`、`min_dwell=169378 clk`、`warn_hi=0`。

### 15.4 屏幕：逐位/逐拍核算结论

只读审计（子代理）逐位核对了 376 位 `disp_tap` 打包解包、RGB/DE/HS/VS 的 3 拍延迟闭环、两处 BRAM 推断写法、107 个引脚约束：**未发现致命缺陷**。已修 1 项中等问题：P7 波形区纵轴只写 0..239 却用 `p7_ry[7:0]` 比较 ⇒ 框底 64 行出现"幽灵曲线"；把 `P7_CVY1` 从 464 改成 400 并加 `p7_vis` 开窗。

**未改（已知，风险/收益不划算）**：`lcd_pclk` 缺 `create_generated_clock`（当前按 sys_clk 建模，实测可工作）；`enc_top_disp.v:674/702/716/841` 用 `negedge key_n` 当异步复位（按键有 RC 消抖，实际风险极低，改动需重新验证按键行为）。

## 16. v9 增量：延迟前馈 / 锁定状态机 / 偏置跟踪 / 全周补偿表（S2–S6）

> 本节是 2026-10-28 上午对 v64 的增量改造。目标只有一个：把"±1″ 机械"这件事
> 从"算法上可能"推到"工程上可交付"。所有改动都不改变既有接口的默认行为
> （前馈默认开、补偿表默认旁路），所以老位流/老上位机仍能跑。

### 16.1 路线修正：不做自适应抽取，改做延迟前馈

原方案（§12.3）打算按转速切换抽取率（64/32/…/1），实测推演后**放弃**，原因有二：

1. **抽取率会改环路动力学**。`decim_avg` 后面就是 PI 环路，抽样率一变，每抽样点的
   环路增益按 N 缩放（N=1 时增益 ×4，N=8 时 ÷2），ωn 与 ζ 全被带偏，稳定性要重做，
   而这正是"广泛适应性"最怕的东西。
2. **带宽本来就够**。固定 LOG2DEC=2（12.5 MHz）时，200 kHz 仍有 **62 点/周期**，
   远超 CORDIC 需要的下限；抽取不是精度瓶颈，**延迟才是**。

真正的瓶颈是：PI 环路跟踪的是"延迟 T 之后的测量值"，对恒速输入的稳态误差为 0，
但上报位置恒滞后 ω·T。2048 PPR、3000 rpm（f_el = 102.4 kHz）、T = 0.72 µs 时

    Δθ = 360° × f_el × T = 360° × 102400 × 0.72e-6 ≈ 26.5° 电角度 ≈ **46″ 机械**

比 ±1″ 大 46 倍。所以 v9 的做法是：**抽取率固定，用前馈把滞后补掉**。

### 16.2 S2 延迟前馈（`rtl/lag_ff.v`，新增）

* 速度观测量直接用 `loop_filter` 的积分器 `omega_pos`（= 每抽样点位置增量，
  ZW=24 位、FRAC=8），它就是天然速度，不需要再微分、不会引入噪声放大。
* 修正量：`corr = (omega_pos × TAU_Q8) >> 8`，饱和 ±REV/4，3 拍流水，1 个 DSP48。
* 修正加在 32 位 `{cycle_cnt, angle}` 上（`pos_rep = pos_full + ff_corr`），
  进位/借位自动完成，上报位置全程连续。
* `TAU_Q8` 默认 **9.0 抽样点（720 ns）**，正是实测流水线延迟 0.59~0.83 µs 的中位值；
  `FF_CFG[0]` 默认 **1**（开启）。现场可读 `0x0127..29` 看实际修正量来标定 T。
* 修正量随速度前馈，不进入环路 ⇒ **不影响稳定性**、不改变闭环带宽。
* 位置型（position）输出用修正值；`pole_counter`、Z 窗口仍用未修正值（见 16.6）。

### 16.3 S3 锁定状态机（`rtl/lock_sm.v`，新增）

INIT → TRACK → LOST 三态，判据是四类"坏样本"的或：幅值越限（低/高）、
`lag_limit`（相位跳变 > 45°）、校正饱和（`cor_sat`）。

| 迁移 | 条件 | 默认门限 |
|---|---|---|
| INIT → TRACK | good 连续 | 12500 样本（1 ms） |
| TRACK → LOST | bad 连续 | 2500 样本（0.2 ms） |
| LOST → TRACK | good 连续 | 12500 样本（1 ms） |

* **不冻结位置输出**。伺服宁可带着 flag 继续跑，也不要看到位置突然冻住后的速度突变。
* 诊断寄存器：`0x0130` 状态、`0x0131` 粘滞位（曾锁定/曾掉锁/当前已锁定，W1C）、
  `0x0132/33` 累计掉锁次数、`0x0134/35` 当前连续坏样本数。
* 为什么需要它：把"上电还没锁定""瞬间毛刺""真的丢信号"三类分开。没有它，
  上位机只能靠幅值报警一个笼统信号，分不清是探头脏了还是转速超了。

### 16.4 S4 偏置慢跟踪（`rtl/bias_track.v`，新增）

* 偏置在角度上**不是常数误差**：θ = atan2(s,c)，偏置把圆搬离原点，误差是 2θ 的正弦项，
  单点补偿按下葫芦浮起瓢。
* sin/cos 是零均值信号 ⇒ 长时均值就是残余偏置。
* **v9.1 改为分块积分**（第一版 EMA 是反馈环，实测把环路带崩，见 16.10 #1）：
  一个窗口（`LOG2N=15`，32768 样本 = 2.62 ms @12.5 MHz）内累加，窗口末
  `bias += 窗口均值`，窗口内 bias 恒定 ⇒ 无连续反馈、一块收敛。
* **默认关闭**：`cfg_bias_en`（0x0122 bit1）复位值 0。上板首版必须与 v64 行为一致，
  验证过再打开（打开后 0x0138..0x013C 可看收敛结果）。
* 只在 `lock_state == TRACK` 时跟踪，`restart` 接一键标定（每次标定重学）。
* 饱和：±8191 LSB（±25% 满量程）置 `bias_big`，提示接线/增益异常。
* 已知边界：12 rpm 以下一个电周期（24 ms）比窗口还长，均值带半周期残差 ⇒ 低速段仍靠标定。
* 只读：`0x0138/39` bias_s、`0x013A/B` bias_c、`0x013C` {big, valid}、`0x0122` bit1 开关。

### 16.5 S5 全周补偿表（`rtl/angle_lut.v` + `host/lut_tool.py`，新增）

刻度误差、安装偏心（1 次谐波）、码盘跳动都是机械角的确定性函数，单点/四点标定
只能消掉 0 次项和 1 次项的一部分，剩下的全周形状必须用表。

* 4096 × 16 位（**2 个 BRAM36**），索引 = 机械角高 12 位，0.0879°/点 ≈ 5.3′。
* 修正量 LSB = 1 个角度 LSB = **0.0097″**（PPR=2048、AW=16），量程 ±0.088°。
* **默认旁路**（`0x0145=0`）：没有外部基准时不启用，既有功能完全不受影响。
* 写表：一条记录 2 次串口事务（桥一次写 2 字节），`host/lut_tool.py` 支持
  CSV → 校验 → 整表写入 → **逐点回读校验**（`0x0145 bit1=1` 让读口跟随表地址）。
* 为什么 4096 点就够：主要成分是 1~2 次谐波，量化残差 ≈ A·2.9e-7，A=50″ 时只有 1.5e-5″。

### 16.6 S6 输出一致性（v9.1 修正：ABZ 改回未修正角度）

**v9 最初的做法**是把 ABZ 也切到 `angle_rep`（与遥测同源）。**实测证明这是错的，已回退**：

- 现象：`tb_enc_top` 里 A 相边沿从 2048 涨到 **4611**，反向 4733，随附 UVW 扇区跳变 24→22、
  位置噪声 max_dev 1763 LSB16。
- 原因：环路积分器（速度）本身有 ±1 LSB 的极限环抖动，乘 `tau=9` 后被放大成 ±9 LSB16 的
  位置抖动；而 ABZ 一个边沿间隔只有 32 LSB16，阈值附近反复穿越就凭空多出边沿。
- 判断：ABZ 是**增量**接口，驱动器只关心"边的相对关系"，固定延迟 ω·T 不累积、不影响计数，
  为它引入抖动是纯亏。**遥测/寄存器回读（`pos_rep`）才用修正值，ABZ 用未修正的 `angle`。**
- UVW 同样用未修正的 `mech_angle`：换向扇区只要 60° 级粗位置，且必须在过零点绝对单调。

⇒ 现在的分工：**遥测 / 寄存器回读 = 修正后位置**（含延迟前馈 + 查表），
**ABZ / UVW / Z = 未修正的原始位置**。两者差的只是"固定延迟"这一项，不是累积误差。

### 16.10 最终验证抓出的三个缺陷（v9.1 修复记录）

这一步的价值就在这里：**S2–S6 各自单测全绿，接进全链路后仍然炸**。三个缺陷都不是单元测试能发现的。

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | `tb_enc_top` 角度 max_dev **1763 LSB16**、UVW 扇区 24→**22**、两次标定结果不再逐位相同 | `bias_track` 第一版把"偏置估计"做成了嵌在校正通路上的**反馈环**（`bias ← EMA(s_cor)`，而 `s_cor = s − ofs − bias`）⇒ 稳态只能补一半，且与 PI 环路持续耦合 | 改成**分块积分**：窗口内 bias 恒定、窗口末 `bias += 均值`（一块收敛、无连续反馈）；并把 `cfg_bias_en`（0x0122 bit1）**复位值设为 0** |
| 2 | A 相边沿 2048→**4611**（反向 4733） | ABZ 吃了 `angle_rep`；环路积分器的 ±1 LSB 极限环被 `tau=9` 放大成 ±9 LSB16，而 ABZ 边沿间隔只有 32 LSB16 | ABZ 改回未修正的 `angle`（见 16.6） |
| 3 | v65 位流 **WNS −1.197 ns**（0 失败端点不成立） | 最差路径 `u_lut/mem_reg → pos_rep 两级 32 位加法 → u_abz/r_ovl[*]/CE`，BRAM 输出直连加法器再进比较器 | 同 #2：ABZ 不再依赖 `pos_rep`，该路径消失 |

教训（写进流程）：
- **估计器不要在被控回路上闭环**；
- **增量接口（ABZ/Z）与绝对位置接口（寄存器/遥测）要分开考虑**，前者对抖动敏感、对固定延迟不敏感；
- **单测全绿 ≠ 集成可靠**，必须跑全链路 tb + 看真实位流的时序报告；
- Vivado 时序失败**照样产出 .bit**，所以"有位流"绝不能当"通过"，必须查 `WNS` 与失败端点数。
