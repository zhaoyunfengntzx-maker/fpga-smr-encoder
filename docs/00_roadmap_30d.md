
## 附录 A：Vivado 工程搭建步骤（照抄即可）

1. **新建工程**
   - Vivado → Create Project → RTL Project（不勾 Do not specify sources）
   - Part：`xc7a35tfgg484-2`（**注意速度等级是 -2**；若板子是 -1 则选 `-1`）
   - 工程名：`enc_top`，路径：`C:\Users\zhaoy\Desktop\FPGA\vivado\enc_top`

2. **添加源文件**
   - Add Sources → Add or create design sources → 把 `rtl/*.v` 全部加入（testbench 用 Add or create simulation sources）

3. **时钟（v1 极简方案，推荐）**
   - **不需要生成任何 IP**：板载 50 MHz 经 BUFG 作为全系统唯一时钟 `clk50`
   - ADC 采样时钟：用 `ODDR`（**D1=0, D2=1**，即反相 180°）把时钟转发到 `ad_clk` 引脚
     （**不要**用 `assign ad_clk = clk;`）
   - ADC 数据保持在 `clk50` **上升沿**捕获（模块内部就是 posedge，不用改代码）
   - 好处：单时钟域、零 CDC、零 IP、综合实现简单
   - **v2 可选升级（降延迟）**：IP Catalog → Clocking Wizard → 输入 50 MHz，输出
     `clk_adc` = 50 MHz/0°、`clk_cap` = 50 MHz/180°、`clk_sys` = 100 MHz；
     再用 `cdc_pulse` 把抽取器的 valid 送到 100 MHz 域（详见 `docs/01` §5.1）

4. **写约束**：把 `constr/enc_top.xdc` 加入，**先把引脚按自己核对过的表改掉**

5. **综合 → 实现 → 生成 bitstream → 下载**

6. **调试（★ ILA 现已是现成可用，不需要再从 IP Catalog 手工搭）**
   - **直接跑 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\run_vivado.ps1 -Tcl tools\ila_debug.tcl -LogFile _synth_work/ila_build.log`**
     ⇒ 产出 `_synth_work/enc_top_ila.bit` + `enc_top_ila.ltx`（34 条命名探针、总位宽 252 bit、1024 深），
     探针清单写到 `_synth_work/ila_probe_list.txt`。探针定义在 `rtl/enc_top.v` 的 `` `ifdef ENC_TOP_ILA `` 段，
     用 `(* mark_debug = "true" *)` 声明，生产版不定义该宏 ⇒ 一个探针都没有、数字不受影响。
   - 已有探针覆盖了原计划要手搭的全部内容：`probe2 dbg_angle_15_0_ 16`、`probe6 dbg_c_dec_15_0_ 16`、
     `probe7 dbg_c_raw_11_0_ 12`、`probe23 dbg_s_dec_15_0_ 16`、`probe24 dbg_s_raw_11_0_ 12`、
     `probe0/4/26/29/32 dbg_a/b/u/v/w_out`、`probe33 dbg_z_window`、`probe25 dbg_stat_byte_7_0_ 8` 等。
     上板时 Program Device 选 `.bit`、同目录加载 `.ltx`；建议触发 `dbg_z_window` 上升沿（⚠️ **不要用 `dbg_adc_valid`**：它在非复位期间恒为 1，`rtl/ad9238_capture.v:163`；要单脉冲就用 `dbg_dec_valid`）。
   - **ILA 采样时钟必须与观测信号同频**；观测 50 MHz 数据时 ILA 用 50 MHz（当前脚本已接 `u_bufg_clk/O`）
   - **下载前把 Hardware Manager 的 JTAG 频率降到 ≤10 MHz**（否则可能一烧就死）
   - 每个 ILA 的采样深度先用 1024，跑通后再加大
   - ★ 生成这条调试版流程**必须放宽一次沙箱权限**（Vivado 生成 ILA IP 时会派生一个子 vivado 进程
     并通过管道收集其输出，受限沙箱下父进程会无限期挂住）
   - ★ **不要把全部探针位拼成一条 probe0 总线**，那会让 `place_design` 挂死；脚本已拆成多条命名探针
   - ★ **时序签核只认生产版**（2026-10-10 16:05:29 版：`sys_clk` WNS **−3.352 ns** / TNS −85.116 / **26 个失败端点** / 10582 端点；ILA 版同为负余量，见 `docs/05` §12.1。失败端点全是 ADC 输入端口，与 12:08 的 −3.271 同源，根因是 §1.19 的诚实 ADC 输入建模），
     签核一律以生产版 `_synth_work/impl_timing.rpt` 为准
