# DPO2024B 上机速查卡（贴在工位旁）

> 配套详细文档：`DPO2024B_user_guide.md`

---

## A. 每次开机必做（3 分钟）

```
1. 三芯电源线 → 可靠接地的插座
2. 开机 → 预热 20 min（谈精度前必须等）
3. CH1 探头尖端 + 地夹 → 前面板 PROBE COMP
4. Default Setup → Autoset → 垂直档位设 1 V/div
5. 看方波：顶角圆→欠补偿，前端尖→过补偿 → 调探头补偿电容
6. CH2/CH3/CH4 各重复一次（每次换探头/换通道都要做）
```

**温度变化 > 10 °C，或要用 ≤5 mV/div：**
```
拔掉全部输入 → Utility → 辅助功能页面 → 校准 → 信号路径 → OK
→ 等"通过" → Menu Off
```

## B. 三条绝对红线

| # | 红线 | 原因 |
|---|---|---|
| 1 | 探头地夹**只接大地**，不接浮地/数字地 | 地夹与电源地短路，接错会冒烟烧板 |
| 2 | 探头衰减比**必须**与示波器设置一致 | 否则读数差 10/100 倍 |
| 3 | 热地电路（市电、开关电源初级）**必须**用隔离变压器 + 差分/隔离探头 | 直接测会炸 |

## C. 屏幕上的三个关键数字，先看它们再调

| 看哪 | 说明 |
|---|---|
| **触发状态**（已触发 / 自动 / 触发?） | 「触发?」= 在等触发，信号没到或电平不对 |
| **触发读数行**（源·斜率·电平·**频率**） | 频率对不上期望值 → 先查信号源/RTL，别怪示波器 |
| **左侧基线指示** | 一眼确认每个通道的 V/div、耦合、带宽、反相 |

## D. 五个快速动作

| 想做 | 一键操作 |
|---|---|
| 触发电平自动居中 | **按一下**触发电平旋钮 |
| 回到干净起点 | **Default Setup** |
| 自动配好显示 | **Autoset**（注意它会改垂直位置） |
| 抓单次事件 | 先设好触发 → 按 **单次**（自动切"正常"模式） |
| 信号不来但想确认通道通不通 | 按 **强制触发** |

---

## E. 五个最常用的触发类型（按场景选）

| 场景 | 触发类型 | 设置要点 |
|---|---|---|
| 一般时钟/信号 | **边沿** | 斜率 + 电平 |
| 抓异常窄/宽脉冲 | **脉冲宽度** | 小于/大于/等于/不等于 |
| 抓"没到满幅"的坏电平 | **欠幅脉冲** | 两个阈值 |
| 抓 FPGA 时序违例 | **建立与保持** | 时钟通道 + 监视通道 |
| 抓 I²C/SPI 协议事件 | **总线** | 需 DPO2EMBD 模块，先在 B1 定义总线 |

**触发不稳就改触发耦合**：工频干扰→**低频抑制**（65 kHz）；高频噪声→**高频抑制**（85 kHz）；抖动→**噪声抑制**。

---

## F. 降噪三选一（别选错）

| 情况 | 用什么 |
|---|---|
| 想降噪**同时还要抓毛刺**、非重复/单次信号 | **FilterVu** |
| 只想滤**一个通道**，或要**在滤波后的信号上触发** | **带宽限制**（20 MHz） |
| 信号**重复**、噪声**随机**、想提高垂直精度 | **平均**（2–512 次） |

⚠️ **FilterVu 不能和平均同时用**；**FilterVu 不影响触发**。

---

## G. 上升时间测量的诚实边界

- 你的示波器自身 **tr = 2.1 ns**；
- 被测信号需要 **tr ≥ 6.3 ns** 才能测得准；
- 测到 ~2 ns → 你测的是**示波器**，不是电路；
- **必须用短地弹簧**，长鳄鱼夹会引入振铃；
- **2 mV/div 会把带宽压到 20 MHz**——别用它测高速小信号。

## H. 数据归档

```
Save 键            → 立即按当前参数保存（屏幕图 / 波形 / 设置）
总线事件表          → 储存事件表 → .csv
Utility → I/O      → USB / 以太网 / GPIB 配置（PC 连接）
前端 USB 口         → U 盘、USB 键盘（输标签）
```

## I. 三条容易忘记但后果严重的

1. **插拔应用模块必须关机**（模块 30 天试用期从首次开机开始计时）；
2. **固件升级过程中绝不能断电或拔 U 盘**；
3. **清洁只能无绒布/微湿软布/75% 异丙醇**，不能刮擦显示屏滤光层。
