# 上板验证清单（2026-10-28，**v66 位流**，含 S2–S6）

> 目的：把"上板"变成一条**可回退、可定位**的路径。每完成一步打个勾，出问题就停在当前步，
> 不要在没验证前一步的情况下跳步 —— 否则现象会混在一起，无法定位是硬件、位流还是上位机。
>
> 配套文档：需求与可行性见 `docs/27_turntable_requirements_feasibility.md`（§15 质量整治、§16 v9 增量与 v9.1 回归修复）。
>
> **上板前先跑一次**：`powershell -NoProfile -ExecutionPolicy Bypass -File tools\final_verify.ps1`
> —— 它会核对源码/默认值/位流时序/回归新鲜度/主机自检，输出 `ALL CHECKS PASSED` 才继续。

## 0. 这次给你的是两个位流，别烧错

| 位流（**入库副本**） | 顶层 | 用途 | 资源 | 时序 |
|---|---|---|---|---|
| `deliverables/data/v66/enc_top_v66.bit`（1,524,668 B） | `enc_top` | **生产用**：无显示 UI，转台正式跑用这个 | LUT 52.48%，BRAM 32/50 | WNS +0.186 / WHS +0.043 |
| `deliverables/data/v66/enc_top_disp_v66.bit`（1,681,601 B） | `enc_top_disp` | **调试用**：带 LCD 显示 | LUT 83.82%，BRAM **48/50** | WNS +0.229 / WHS +0.024 |

> 干净克隆里只有上表 `deliverables/data/v66/` 的入库副本。烧写前用 SHA256 认文件（`deliverables/data/README.md` §2.0a）：

## 1. 只上电，不接信号（5 分钟）

- [ ] 电流正常（3.3 V / 1.2 V 无异常发热），`sys_clk` 50 MHz 有波形
- [ ] 串口（2 Mbaud）能打开，读版本寄存器 `0x0000` 有应答（应是 `0x000E`，v66 的 BUILD_ID）
- [ ] 若烧的是显示位流：屏幕亮、字符正常、没有花屏/偏移
- [ ] 网口灯亮，`ping` 开发板 IP 通

**这一步的意义**：把"能不能活"和"信号对不对"分开。这里不通过，后面全是噪声。

## 2. ⚠ 极对数检查（**UVW 默认已开启**，上电前必做）

`reg_file` 复位值已从 `0x40` 改成 **`0xC0`**（UVW 使能）。UVW 的相位正确**取决于 `0x0100`（极对数）填对**：

- [ ] 读 `0x0100`，确认它等于**电机真实极对数 P**
- [ ] **不确定就先关掉**：写 `0x0109 = 0x40`（只留 ABZ），等确认 P 后再开
- [ ] 若驱动器不用 UVW 做上电换向，建议保持关闭：UVW 只是 3 根快沿输出，纯 EMI 噪声源

> 为什么这么小心：UVW 相位错 → 换向错 → 转矩反向/堵转。这是唯一一个"配错会伤机构"的寄存器。

## 3. 接模拟信号源（代替编码器，30 分钟）

用信号源给 1 kHz、**8 Vpp**、直流偏置 0 V 的正余弦（模拟 EI58 放大后的信号）：

- [ ] 幅值诊断在正常区（不是 60%/120% 告警边界）
- [ ] 偏置诊断接近 0，正交误差诊断 < 1°
- [ ] 角度输出连续、单调（正转递增、反转递减），无跳变
- [ ] `0x0130` 读锁定状态 = **1（TRACK）**；`0x0131` bit2 = 1
- [ ] `0x0756`（以太网错误计数）不再随帧数增长 ← 本轮修的 `gmii_rx_err` 极性

**这一步验证的是模拟前端 + ADC + 数字校正链**，与转速无关。

## 4. 一键标定（10 分钟）

- [ ] 触发标定（`0x0502`），窗口内转动 ≥ 1 整转
- [ ] 校正前残差 ≈ 20.98°，校正后 ≈ 0.0165°（1273× 抑制）
- [ ] 标定结果写回后，角度零点稳定（连续两次标定结果一致，v66 已验证逐位相同）

## 5. 转起来（30 分钟）

- [ ] 100 rpm 起转，角度平滑无台阶
- [ ] 1000 rpm：速度读数稳定，±1% 以内
- [ ] 3000 rpm：不失锁、角度不跳变、ABZ 输出正常
- [ ] 5000 rpm（若机构允许）：EI58 机械上限，程序按 200 kHz 设计
- [ ] 急停/断电再上电：多圈计数不跳变（或按 homing 流程回零）

## 5b. v66 新增功能核对（15 分钟，**按顺序做，每步都可回退**）

**① 延迟前馈（默认已开，`0x0122` bit0=1）**

- [ ] 读 `0x0124..26`（FF_SPEED，24 位有符号）→ 转起来后应随转速线性变化，静止时 ≈ 0
- [ ] 读 `0x0127..29`（FF_CORR）→ 3000 rpm 时应约为一个周期的 **7%**（≈26.5° 电角度）
- [ ] 对比：写 `0x0122 = 0x00` 再读位置寄存器，与 bit0=1 时差的就是补偿量

**② 锁定状态机（只读诊断）**

- [ ] 正常运行时 `0x0130 = 01`，`0x0134/35`（连续坏样本）应接近 0
- [ ] 拔掉信号线：`0x0130` 变 2（LOST），`0x0131` bit1 置位，`0x0132/33` 计数 +1
- [ ] 插回信号：几 ms 内回到 01，`0x0131` bit0=1
- [ ] 写 `0x0131 = 0xFF` 可清粘滞位
- [ ] **注意**：掉锁时位置输出**不会冻结**（设计如此，伺服宁可带 flag 继续跑）⇒ 主机必须看 `0x0130` 判断可信度

**③ 偏置慢跟踪（默认关闭，`0x0122` bit1=0）**

- [ ] 先不动它。等 ①②④ 都验完，再写 `0x0122 = 0x03` 打开
- [ ] 打开后每 2.6 ms 一块，读 `0x0138/39`、`0x013A/B`，应稳定在几百 LSB 以内
- [ ] `0x013C` bit0（valid）= 1；bit1（big）= 0。若 big=1 说明偏置超 ±8191 LSB，查接线/增益
- [ ] 关掉（写回 `0x0122 = 0x01`）后偏置回 0，角度不应有跳变

**④ 全周补偿表（默认旁路，`0x0145` bit0=0）**

- [ ] 没有 ±0.5″ 基准之前**不要开**。表内容上电未定义，但旁路时输出恒 0
- [ ] 有基准后：`python host\lut_tool.py --upload err.csv --port COM7 --verify --enable`
- [ ] 写完读 `0x0146/47` 抽查几个点，与 CSV 换算值一致（1 LSB = 0.00966″）

## 6. 以太网（本轮重点修的就是它，20 分钟）

**满速连续流下**：

- [ ] `ping -n 100 <板子IP>` → **100/100**（修前是 ~1/3）
- [ ] 抓包连续 10 次，每次第一帧都完整（修前前 1~2 帧必错）
- [ ] `0x0756` 错误计数保持 0 或很小
- [ ] 上位机"开流"按钮不卡界面（修前最坏卡 5 s）
- [ ] 拔网线再插回：上位机 3 s 内报"链路无数据"、15 s 内自动重连（修前界面一直显示绿色）

## 7. 长时间（2 小时）

- [ ] 连续跑 2 h，记录：丢包率、CRC 错误数、FPGA 温度、电源纹波
- [ ] 上位机日志无异常断连
- [ ] `0x0132/33`（累计掉锁）保持 0

## 出问题时的定位顺序

| 现象 | 先查 |
|---|---|
| 上电不亮/无时钟 | 电源、晶振、复位（`key_n`） |
| 串口读不到版本 | CH340E 驱动、波特率 2 Mbaud、TX/RX 是否交叉 |
| `0x0000` 不是 `0x000E` | 烧错位流（v66 之前是 0x000D） |
| 角度乱跳 | 先读 `0x0130` 是否 TRACK；再看幅值是否削顶（8 Vpp 只占满量程 80%） |
| 角度有小幅周期性误差 | 前馈 tau 与实际延迟不匹配：改 `0x0120/21`（默认 2304 = 720 ns） |
| ping 通但抓包丢首帧 | 是否烧的是 v66 位流（`sof` 修复在这一版） |
| 屏幕花屏 | 是否用了 disp 位流、LCD 排线、`lcd_pclk` 时序 |

## 已知但本轮**未改**的项（不影响上板，记录在案）

1. `lcd_pclk` 没有 `create_generated_clock`（当前按 `sys_clk` 建模，实测可工作）——改约束需重新验证 LCD 采样窗口，收益低风险高。
2. `enc_top_disp.v` 有 4 处用 `negedge key_n` 当异步复位（按键有 RC 消抖，实际风险极低）。
3. 无 MDIO：100 Mbps 链路不通（只支持 1000 Mbps 协商）。
4. `eth_reply` 的 fbuf 只有 128 B：`ping -l ≥ 86` 会被截断（默认 32 字节正常）。
5. Z 信号输入**未实现**（按你的要求先不接）：需要在 J5 上确认一个空闲脚 + AM26LS32 接收电路。
6. **偏置慢跟踪默认关闭**（`0x0122` bit1=0）：它动的是校正通路，第一次上板先保持与 v64 一致的行为。
7. **ABZ/UVW 用未修正的角度**（寄存器回读才是修正后的）：增量接口对抖动敏感、对固定延迟不敏感，见 §16.10。
8. 显示位流 BRAM 48/50（96%），再加缓存需要先删东西；生产位流还有 18 块。
